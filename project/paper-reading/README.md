# 每日论文阅读与学术写作

每天选取 3 篇近三年的 MobiCom / SIGCOMM 正式研究论文，通过阅读原文、拆解论证和英文练习积累科研写作经验。按北京时间日期归档，以 DOI 或规范标题避免重复收录。

## 如何使用

每天建议用 60–90 分钟完成 1 篇精读、2 篇定向阅读和一段 120–180 词的英文练习。先打开每日记录，按推荐章节阅读，再用自己的话完成练习；提交原稿后再做逐句修改。

记录中的论文事实附来源及章节或图表位置；写作分析和表达框架是助手的学习建议。笔记生成不代表本人已完成阅读，个人阅读、练习与修改状态由本人实际进展更新。
