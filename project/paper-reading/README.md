# 助手每日论文研读与改稿训练

由助手研读近三年的 MobiCom / SIGCOMM 正式研究论文，自己完成英文写作与改稿练习，积累帮助作者修改论文时可查用的案例。首轮试跑目标为每天4篇、每周28篇，实际数量受用户设定的私人用量预算约束。按北京时间日期归档，以 DOI 或规范标题避免重复收录。

选文优先无线组网、无线感知及交叉方向，包括分布式感知、UWB与毫米波雷达、Wi-Fi感知、同步、定位和低功耗无线网络。按相关性与可获取的正式论文正文选择，不为会议数量均衡而优先收录无关主题。

## 助手如何完成与复用训练

每天完成原文研读、论证拆解和具体改稿，记录“助手自拟待改句或段落—问题诊断—完整改稿—修改理由—适用边界”。练习由助手完成，无需作者阅读论文、提交作业或填写进度。

后续帮助作者改稿时，先按章节和问题检索下方案例，再核对当前稿件的意图、事实和修改范围，只应用相关改法。记录中的论文事实附来源与位置；训练差例由助手自拟，不是原论文或作者稿件中的句子。新经验保留为助手参考，不自动升级为作者已确认的写作规范。

## 多维研读框架

论文既是论证，也是由语言、图表和版面共同构成的表达。下面是研读范围；2026-11-05首轮三篇主要完成论证与证据方面的改稿，追加的Medusa完成系统边界、配置权衡、原创结构草图及搭配练习，尚未核验其原始页面的视觉效果。

| 维度 | 具体观察什么 | 助手完成什么练习 |
| --- | --- | --- |
| 研究问题与证据 | 要求、缺口、观察、方法、实验是否连接；结论强度是否合适 | 修正一处逻辑缺口或证据归因，说明依据 |
| 篇章与段落 | 信息出现顺序、段首任务、段间衔接、贡献如何展开 | 完成一个段落的组织或衔接改写 |
| 排版 | 双栏阅读顺序、段落密度、留白、图表位置、跨页关系 | 针对实际页面提出具体调整，区分模板限制和作者选择 |
| 图文配合 | 正文什么时候引图；图注交代什么；图后怎样解释结果 | 自拟一组引图句、图注和解释句，使三者分工明确 |
| 图形设计 | 图要说明什么；信息流、箭头、坐标、单位、颜色、子图比较及最终尺寸可读性 | 给出原创图形布局或修改方案，不编造数据，不复制原图 |
| 语法与句式 | 主谓、时态、冠词、指代、信息重心、长句拆合与逻辑关系 | 完成改稿并解释含义、重点和语气的变化 |
| 词语与搭配 | 动词是否精准、搭配是否自然、论断强弱是否符合证据 | 记录语境、含义、适用范围和原创例句，辨别容易误用的替换 |

除上述表达维度，还学习作者怎样界定研究、建立证据和帮助读者作出判断：

| 维度 | 具体观察什么 | 后续改稿用途 |
| --- | --- | --- |
| 研究问题与系统模型 | 输入、输出、目标、设备能力、约束及排除的问题 | 明确研究对象，避免把实现步骤当成目标 |
| 创新定位 | 相对已有工作，推进的是问题、观察、方法还是适用条件 | 写清具体差异，使贡献可检查 |
| 概念与指标定义 | 可靠、实时、低成本怎样操作化；单位、分母及统计口径是什么 | 统一摘要、方法与实验中的概念含义 |
| 数学表达与物理意义 | 现实条件怎样进入变量、约束、目标和假设 | 补齐公式的必要解释，检查推导与文字是否一致 |
| 实验设计 | 每个实验的问题，基线、消融和敏感性分析的作用 | 判断证据支持到哪里，识别最小必要补充 |
| 公平性与可信度 | 信息、资源、调参预算、重复测量、波动与统计方式 | 防止错误归因或只挑最好结果，交代影响判断的条件 |
| 失败案例与适用边界 | 失效条件、机制原因，以及原理限制和实现限制的区别 | 将笼统局限写成可供读者使用的判断 |
| 读者的理解过程 | 例子、类比、反例、直觉与正式定义怎样配合 | 针对理解难点补解释，避免不必要的展开 |
| 审稿人视角 | 最可能被质疑的贡献、假设和证据，作者怎样回应 | 用实际依据回答关键疑问，保持结论强度适当 |
| 信息取舍与压缩 | 标题、摘要、正文、附录各保留什么 | 保住核心逻辑，压缩重复或移动次要细节 |

每篇根据自身特点和当前改稿需求选择1–2个重点，并说明选择原因。例如，机制复杂的论文侧重模型与解释，实验丰富的论文侧重对照和可信度，视觉表达突出的论文侧重图文设计。维度不是逐篇打满的检查表；在多天的记录中检查覆盖情况和重复程度。每篇仍需理解研究内容、核对关键证据；其余维度只记录有依据的观察。每个重点至少留下一个具体练习成果，不能止于“布局清晰”“用词准确”等评价。

视觉分析必须查看PDF实际页面或渲染图，记录页码和图号；仅取得文本时不评价排版与图片。图表相关任务按仓库[图表与PPT交付规范](../../docs/fastset-journal-retrospective/04-图表与PPT交付.md)读取适用要求，不能只凭源码判断成品。

词语学习每天选2–3项即可，保存“来源位置—语境—表达作用—适用边界—原创例句”。目标是精确自然的表达；例如表示减轻问题的词，不能随意换成表示彻底消除问题的词。短引文与自拟例句明确区分，避免大段摘抄。

训练案例按维度和触发问题持续加入下方索引。后续在新内容中检查同一改法是否仍适用，记录必要修正；不把阅读速度、篇数或笔记长度当作改稿质量的证明。

## 在实际改稿中使用

收到论文修改任务后，先明确当前章节、读者及修改范围，再按索引查找相关案例。实际修改中记录“遇到的问题—采用的案例—作出的改动—保留的原意与证据”，无需每次向作者展示完整学习过程。案例与当前稿件的假设或表达目标不一致时，不机械套用；缺少实验或定义时标出证据缺口，不补造结果。

新增迁移记录应以实际改稿为依据，并经授权后才可公开用户稿件内容。本公开目录优先保存公开论文依据和助手原创案例；具体稿件的改动记录留在对应授权位置。

## 耗时与用量测量

后续每批记录检索开始、正文与图表核对、练习完成和上传结束的时间；如并行处理，分别区分单篇经过时间与整批总时间。记录所选重点和完成程度，使不同批次可比较，不把未实测的时间填成实际值。

在读取额度的工具可用时，采集整批开始与结束的周用量读数及重置时间。读数属于全账户，差值只能直接称为该时段的账户用量变化；同期其他活动、显示精度或跨重置窗口会影响判断。显示不变不等于零消耗，也不能把整批平均值当成实测单篇成本。

账户额度、预算数值、标识与运行状态只保存在本地私人测量记录或任务设置中，不提交公开仓库。先对一篇取得完整起止观测，再判断能否继续当日目标；根据用户选定的预算和可比较样本逐步调整。保留显示精度和收尾余量，接近预算时停止新增研读，不为完成篇数牺牲质量；无法取得可靠用量读数时不追加论文。账户共享读数无法提供精确的单篇计费或硬性预算限制，未经测量的历史试跑不追认为已知成本。
