# 组会 PPT：理解、依据与交付检查表

与[RFDT 协作复盘](README.md)配合使用。以下是可复用模板，不要求每次填完全部表格，也不是新增审批流程。

## 开始前的四个定位

- 当前主文件与用户手动修改状态：
- 本次只修改什么，保留什么（含讲稿、语言版本）：
- 听众已知什么，这部分必须先解释什么：
- 成功标准：听众看完能回答什么，而不是新增多少页：

## 方法问题链

| 当前具体问题 | 为什么现有办法失效 | 作者采取的步骤 | 仍未解决什么 | 下一页依据 |
|---|---|---|---|---|
| | | | | |

每页回答一个明确问题。过程示意中的变量变化，与实际优化变量不同，应明确对应关系。

## 公式解释卡

| 公式／来源 | 它算什么 | 已知配置与观测 | 当前待估参数 | 中间量如何获得 | 输出用在哪里 |
|---|---|---|---|---|---|
| | | | | | |

检查：符号是不是跨公式换了含义？权重是实数比例还是复值系数？经典理论与作者新构造分别是什么？连续、可微、准确分别有什么证据？没有核实的实现细节记录为待查，不编造。

## 实验证据卡

| 实验及子图 | 仿真／实测 | 输入与设备用途 | 真值来源 | 基线与配置 | 指标／单位／轴 | 直接观察 | 作者解释／我们的判断 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

主性能和每个重点应用都有定量图或可追溯数值。另记图文冲突、校准与测试划分、正文有数值但无图的结果。不要为了完整而自行补图中不存在的数据。

## 逐页提纲

| 页的任务 | 可直接放页面的 point | 图／公式／数据来源 | 与下一页的连接 |
|---|---|---|---|
| | | | |

页面 point 保留逻辑、数值、条件；讲稿解释更多细节，不能靠讲稿掩盖页面主线缺失。

## 修改与验收记录

- 读取的主文件版本或校验值：
- 变更页（按标题定位，附当前页码）：
- 未变页／图片／备注保留检查：
- 导出文件与页数：
- 实际查看的页面及可读性问题：
- 未解决事项、用户未确认事项：
- 回退范围及是否保留后续手改：

通过项只覆盖实际检查范围；截图中公式完整、caption可读不代表解释已经清楚。
