# 03 论文与科研表达：保留意图，把理由讲透

本文件补充[原有论文写作指南](../../如何写一篇论文.md)。原指南讨论一篇工作的整体逻辑，这里重点讨论助手怎样修改已有论文、整理期刊扩展和与作者沟通。

## 1. 最小修改是范围要求，不是降低质量

**明确偏好：** 作者没有要求重写时，保留原来的背景、方法和叙述逻辑，只修改新证据真正影响的部分。

开改前区分：

| 修改类型 | 应做的事情 |
|---|---|
| 语言润色 | 保留事实、论证顺序和技术含义，改善句子 |
| 局部补充 | 补缺失定义、实验依据或一句解释 |
| 结构调整 | 明确需要移动哪些段落、图表和引用 |
| 科学内容更新 | 核对新结果，修改相关结论及其上下文 |

不能以“润色”为名删掉作者的背景铺垫，也不能把熟悉的模板套在整篇论文上。新增一项实验，不意味着 Abstract、Introduction 和方法都应重写。

先交付作者要看的局部修改，再在必要时说明其他建议。不要把可选建议自动加入主稿。

### 投稿前修改补充：先确认段落任务，再改句子

**实践总结，2026-11-11：** 每段先用一句中文概括大意，再连续读这些概括，检查研究要求、现有不足、设计依据和实验验证是否顺着展开。局部修改后，至少连读前后两个段落；移动段落后，检查原位置与新位置的衔接。

本次曾出现“单句通顺、放回全文却接不上”的问题。前段介绍神经接收机的优势，下一段应结合环境变化引出适应问题；介绍切分时，应先讲信道估计的物理作用，再展开训练安排。设计依据和实现挑战各有任务，提前把后一个挑战的答案塞进前段，会打乱论证顺序。

过渡词要表达实际关系：补充实现细节可以用 more specifically；从优势转向部署困难可以用 however。检查重点是前后关系，连接词的数量和句式整齐程度不作为质量目标。

## 2. 把研究问题与解决办法分开

本次作者反复强调：研究问题是怎样快速完成在线适应，而不是“怎样选择切分”本身。切分是实现目标的方法。

这个区别可以迁移到任何领域：

- “设计一种压缩算法”是方法；在带宽约束下完成可靠传输才可能是问题。
- “加入一个注意力模块”是实现；恢复缺失信息或提高特定条件下的识别可靠性才是问题。
- “优化一个评分指标”是工具；帮助选择真实使用中更合适的方案才是目的。

Introduction 先说明问题和现有缺口，再引出核心想法。不要把自己实现时遇到的每个工程步骤都包装成研究挑战。

## 3. Abstract 与 Introduction 不装入操作日志

摘要保留问题、核心办法、主要验证和结果。某次检查的时间点、所有 seed、每个预算上限等通常不适合放进摘要。

Introduction 的背景应尽快落到本文要解决的具体问题。相关工作要说明它们的有效之处和仍存在的缺口，不用笼统否定别人来衬托自己。

本次明确要求新增相关引用优先使用高质量、正式发表的工作。迁移到其他领域时，应遵守该领域可靠来源标准；不能机械地用计算机会议分级评价所有学科。

作者要求保留的原句要尊重；发现它与证据直接冲突时，应指出具体冲突，而不是悄悄改变含义。

## 4. 实验段落要形成一条完整解释

推荐四个问题依次展开，篇幅按实验复杂度裁剪：

1. 为什么做这个实验？
2. 比较了什么，关键条件是什么？
3. 图中最值得注意的结果是什么？
4. 这个结果怎样解释方法的作用？

例如，不写：

> 我们进行了充分实验，展示了优越性能。

而写：

> 图 X 比较两种方案达到相同目标所需的时间。新方案减少了完整模型的更新次数，因此在该场景中用更短时间恢复了目标精度。

只有数据确实支持时，才使用相应因果解释。图中曲线重叠、差异很小或某个对照更好，简洁说明即可。

正文不能只有数值复述，也不能全是泛泛解释。主实验通常需要交代核心成本和工作量；参数敏感性实验不必把每个内部循环的细节都写一遍。

**本次使用的方法：** 先用一句话概括趋势或主要比较，保留一个关键数字和一个必要对照，其余读数由图表承担。原因解释须有模型机制或对照结果支持；证据只能说明相关变化时，就按观察描述。

**记录核实：** 一次实验叙述修改补充了实验目的和结果解释，同时将该次统计范围内、排除公式与 LaTeX 命令的英文词数从 2,661 降至 2,594。这个案例说明，删除逐点读数可以为解释腾出空间；该词数仅描述一次局部改稿。

Setup 应让初读者迅速找到比较任务、共同条件、数据集职责、评价指标与基线用途。离线搜索的固定预算和在线首次达标停止应分别说明。本项目最后将硬件软件放在 setup 末尾；新稿按章节逻辑和当前要求安排。

## 5. 自然表达不等于隐去限制

**明确偏好：** 不要把“不能因此说明……”“不承诺……”“目前无法判定……”作为每段固定结尾。作者反感的是空泛、自我防御、与图无关的套话。

更好的写法是把有用的范围直接说清楚：

| 空泛写法 | 具体写法 |
|---|---|
| “这不能说明在所有环境都更优。” | “固定方案在本节比较的三个环境中均减少了适应时间。” |
| “不能保证真实部署性能。” | “测量覆盖输入处理与训练；模型首次加载属于另一个启动阶段。” |
| “还有许多因素有待研究。” | “未来将把现有方法接入真实接收链路，评价数据获取和模型切换成本。” |

**科学底线：** 没有证据就不能把“可能影响不大”写成“我们已证明影响不大”。表达可以肯定、清楚，结论仍须与证据相符。

## 6. Discussion 解决读者问题，不堆免责声明

本次明确要求 Discussion 聚焦少量主题，说明已经考虑了什么、现有结果解决到哪里、剩下哪些属于工程实现或未来研究。

每个主题可以用三句话完成：

1. 实际系统可能遇到什么问题；
2. 现有方法或实验已经支持什么；
3. 后续需要补哪一部分。

投稿前进一步确认的组织方法是：先说明某个因素会影响什么，再交代本文怎样处理、现有证据回答了什么，最后介绍其他处理方式或下一步实现。篇幅依问题裁剪。补充材料已有对应实验时，给出明确引用；实际接收机集成属于后续工作时，写清需要接入的具体环节。每段围绕一个读者会提出的问题，避免泛泛罗列限制。

不能把核心研究假设全部移到 Discussion，避免读者在读完结果后才知道训练用了什么信息。方法成立所必需的输入、监督和条件，要在方法与 setup 中交代。

工程细节不必无限扩展成新实验。相反，若某个细节决定了当前结论是否成立，它就不能仅靠“未来工作”处理。

## 7. 期刊扩展要讲清“推进了什么”

作者最终明确的叙述顺序是：

> 会议版做了什么 → 期刊版进一步改进什么 → 新增哪些实验 → 深入优化时发现什么 → 新流程体现什么优势。

这比罗列“新增了几张图、几个城市、几个候选”更有说服力。新增实验应当服务于新认识或更完整的证据。

Summary of Differences（SoD）可以包含：

- 一段说明继承的基础；
- 一段概括改进和新发现；
- “具体提升—对应章节”的表格；
- 少量直接比较图；
- 原会议论文的完整引用，以及“具体细节见正文”的指引。

早期曾要求 SoD 控制在两页以内；投稿前已明确允许三页。当前按内容和阅读顺序安排，页数及是否放图仍属项目选择。

比较旧方案与新方案时，说明两者是否在当前统一条件下重测。不能把历史论文的旧计时与新硬件结果直接当作纯方法改进。

期刊扩展可先概括“新增观察改变了我们对方法的什么理解”，再围绕这项认识组织实验。某个阶段已经足以恢复目标性能，就是能连接设计、停止流程与消融分析的观察；具体结论仍由对应实验支持。

三份材料分别组织：主稿解释问题、方法和主要证据；SoD 解释继承基础、新增认识与验证；补充材料展开条件、分析和复现细节。三份材料共享术语、数据定义和结论。补充材料中的图也要有实验目的与结果分析，主稿在相关问题处引用。

涉及作者变更时，SoD 可按“已有工作概述—作者变更及实际贡献—期刊扩展”展开。贡献说明采用作者确认的事实。公开科研笔记仅保留组织方法，私人署名沟通留在私人记录中。

## 8. 当前反馈优先，不能把写作习惯变成教条

本次曾要求正文不要反复讲会议版与期刊版的区别；后来导师要求在 Introduction 增加一小段差异说明。正确处理是增加这一小段，而不是继续坚持旧要求，也不是把全文改成版本对照报告。

同样：

- “硬件先写”后来改成“先讲实验场景，硬件后置”；
- “页数尽量撑满”不能覆盖后来提出的版面美观要求；
- “删除关键词”是当次修改意见，正式提交前仍要查目标期刊的实际要求；
- 共同贡献、单位、通信作者等以作者确认的信息为准，不能从旧稿擅自推断。

记录这些变化的目的，是避免下次按过期指令工作。

## 9. 给导师的邮件与正文不是同一种文体

邮件先交代背景和要请老师判断的事项，再用几条解释会议版与期刊版分别完成了什么。保留技术逻辑，减少参数、文件名和内部执行细节。

**明确偏好：** 中文第一次出现技术名词时用“中文（英文）”，后续用英文；iteration、epoch 等不要翻成含混的“轮”。

没有提供的作者履历、贡献比例和私人原因不补写。邮件只是草稿，不能替作者对外发送。

## 10. 论文交付检查

- 修改是否超出当前要求；
- 主要术语、缩写和方法标签是否一致；
- 每段结论是否有对应图表或依据；
- 公式、代码语义与正文是否相符；
- 图表顺序是否跟随叙述；
- 原稿需要保留的内容是否还在；
- 新增或修改内容是否按要求标出；
- 最终 PDF 是否来自指定主稿。

这些检查用于减少返工，不意味着每次小修改都要重新审查整个研究。

## 11. 同一设计跨章节核对，贡献分析对照实际变量

**2026-11-11 补充，作者确认采用的检查方法：** 把同一设计在摘要、引言、方法、图示、实验解释和结论中的表述放在一起读。每处可以详略不同，输入、作用、监督来源和结论应相容。例如，physics-guided 的含义应通过信道估计的物理作用解释，使不同章节始终指向同一设计。

建立少量固定名称即可：概念、采用的术语、首次解释位置、图中名称。专业术语是否需要解释，由读者理解所需决定。指代不清时补回具体对象；已有明确含义的从句和专业表述按语义保留。

归因前列清每组比较改变了什么：结构、参数预算、预训练方式、初始化、监督目标、在线更新策略。相同初始化下的策略对照与分别预训练的完整方案对照回答不同问题，结论分别对应。共同参数预算是比较条件之一。数据用于训练、停止验证、结构选择还是独立测试，也应标明，防止把选择过程中的表现直接解释成独立泛化证据。

以上检查用于安排证据和准确解释已有结果，新增实验按当前任务授权执行。
