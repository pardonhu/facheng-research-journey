# 04 图表与 PPT 交付：先确定要表达什么

本次实际工作主要是论文图表和 LaTeX。PPT 部分结合仓库已有的[组会指南](../../如何制作组会.md)提炼迁移原则，不声称这些做法已经在本次完成的 PPT 中验证。

## 1. 先选证据，再选图型

每张图先回答：“读者看完应该知道什么？”

| 要回答的问题 | 常用表达方式 | 最容易犯的错 |
|---|---|---|
| 谁达到相同目标更快 | 时间柱图、性能随时间的轨迹 | 只画 iteration，却忽略每步成本 |
| 性能与成本如何取舍 | 散点、Pareto 图 | 坐标或停止规则让所有点挤在一起，却只改美观 |
| 一个因素如何影响结果 | 参数敏感性曲线 | 同时变化多个因素，仍称单因素实验 |
| 哪些模块起作用 | 有明确共同条件的消融图 | 把所有条件下“都不可缺少”预写成结论 |
| 成本来自哪里 | 有总值的堆叠柱图 | 为凑四五段，把未独立测量的开销拆出来 |
| 系统或场景怎样构成 | 流程图、位置图、示意图 | 把示意图当实测几何，或标签与数据角色不符 |

图型解决不了实验定义的问题。指标挤在一个阈值附近时，先弄清比较问题；不要用换坐标或平滑制造更强的差异。

## 2. 风格统一是为了让读者少记东西

**明确偏好：**

- 同一个方法在全文保持相同颜色、名称、线型和 marker；
- 颜色之外再用形状或线型区分；
- PDF 图不要额外铺底色；
- 避免难辨认的五角星，优先清晰的圆、方、三角等；
- 轴、刻度和标签要清楚，不能为省空间把必要坐标省掉；
- 图例能放图内且不遮挡，就放图内；放图外时靠近主体，尽量不超过两行。

**不应机械继承的内容：** 本次讨论过多套色系，也有明确的字体要求。新项目先确定一份风格样张，再统一应用；不要把一个历史色值或某份示例代码永久当作所有论文的标准。

本次曾明确给出一套高区分度色系，并随后要求取消背景填充。后来的具体要求应覆盖色板示例中的背景设置。

## 3. 在最终显示尺寸下验收

大图里能看清，不代表缩进双栏论文后能看清。PPT 投影能看清，也不是把论文 PDF 截图放大就一定能做到。

需要检查：

- 最小字号、上下标、图例和误差条是否可读；
- 线宽、marker 大小和密度是否协调；
- 标签是否被柱子、线条或另一子图遮住；
- 各子图的横轴、纵轴是否真正对齐；
- 图外留白是否在抢占正文空间；
- 背景网格是否帮助读数，而不是淹没数据。

本项目要求论文轴标签和刻度使用黑色 Times New Roman，并与最终版面的正文、caption 尺寸协调。PPT 不直接照搬这个字号，而应按投影尺寸重新设计。

## 4. 密度高不等于内容全塞进去

作者希望图的信息密度更高，适合时可合并相关子图，一张图容纳五六条可区分曲线。但这不是每张图都必须放满六条线。

合并前检查：

1. 是否回答同一个问题；
2. 坐标和单位是否可比较；
3. 图例是否仍能快速理解；
4. 是否需要用不合理缩放才能放下；
5. 合并后正文能否清楚引用。

若线条重叠是实际结果，正文简洁说明；不要把线条人为错开后让读者误以为性能不同。

## 5. 显示范围可以调整，数据不能悄悄调整

作者曾要求裁剪没有更多信息的高 SNR 区域、降低 marker 密度和加入局部放大。这些是显示选择。

可以：

- 截取与论证相关的轴范围，并保留原始数据；
- 只在部分已测点放 marker，曲线仍来自实际数据；
- 使用 log 坐标压缩跨度，并明确坐标性质；
- 在主图内做 inset，避免单独小图浪费空间。

不能：

- 将没有测量的区间画成实测；
- 为了“更柔和”擅自平滑，或只挑好看的 seed；
- 把零误码换成未说明的小正数；
- 把未达到相同目标的耗时称为达标加速比；
- 用裁剪隐藏会改变主要结论的结果。

具体截到多少 dB、主图用不用 log、marker 每隔几个点，属于项目决定。不能迁移成通用固定值。

## 6. 成本分解要能加回总数

堆叠图顶部给总时间，内部表达真实测得的分量。名称应反映实际操作，避免一层叫 input、另一层又包含同一设备传输。

本次要求图看起来更完整，不意味着可以凭空拆出多个部分。若只可靠测到了两项，就先展示两项；需要更多分量，必须有对应测量。

对不同重复运行取统计值时，确保分量之和与总量相容，并说明采用哪次运行或哪种汇总方式。

## 7. 排版围绕段落和阅读顺序

**明确偏好：**

- 图尽量靠近首次讨论的位置；
- 一组结果先讲性能，紧接着讲对应时间，再讲其他因素；
- 避免一页几乎全是图只剩一行正文；
- 避免两张图中间夹一行孤立正文；
- 避免段落最后一行只剩几个词；
- 相同层级、相同功能的图尽量同尺寸、并排对齐；
- 参考文献自然排版，不为了凑页数强行挤压。

本次讨论过每页图占比和页数目标，并曾因整体变丑要求回退。因此，应保留可回退版本，先试代表性页面，再应用全篇。

不要用全局负间距修复局部空白。局部问题先定位：图自身留白、caption、float 间距、段落分页，还是图声明放得太早。

## 8. PPT：保留论证，重新组织阅读负担

原有组会指南的主线继续适用：

> 问题为什么重要 → 系统模型与核心想法 → 挑战与办法 → 实验设置与结果 → 总结和个人判断。

根据本次经历，迁移到 PPT 的建议是：

- 一页围绕一个明确问题，可以有多个相关图，但不让听众同时解读几套无关坐标。
- 标题表达这一页的任务或主要判断，正文和图共同支撑它。
- 首次出现的方法和指标要解释，再进入结果比较。
- 不直接堆放整段论文；保留结论、关键证据和必要条件。
- 对讲述重要的细节可分步呈现，不用大量装饰动画替代解释。
- 先做一张方法页和一张结果页作为样张，再批量排版。
- 科研比较图保留可编辑来源；需要 PPTX 就交 PPTX，不擅自换成网页演示。

这些属于迁移建议，不是作者已经逐条确认的模板。新任务对用途、听众、时长和格式有更具体要求时，以新要求为准。

## 9. 交付的是可复用的证据，不只是一张图片

科研图表建议包含：

- 原始或整理后的数据表；
- 绘图代码与明确的风格入口；
- PDF/SVG 等适合论文的输出，以及便于预览的图；
- 方法标签、单位、数据版本和对应段落。

本次作者希望画图数据内嵌代码、随 LaTeX 打包，便于自己细调。可采用嵌入数据的自包含脚本，但仍保留数据来源，不能失去与原始统计的对应关系。

最终交付前，打开真正的主 PDF 或演示文件。若作者需要查看一张特定图，给出它的明确位置，而不是让作者在一堆同名文件里猜。
