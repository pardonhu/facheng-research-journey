# 电芯UWB组网

**目标：中心周期性收集200～300个电芯的数据，重点验证100 ms内收齐的能力。** 每条电芯数据暂按32 bit，先做可行性验证。

整理日期：2026-11-05。原工作区为一次Windows本机硬件调试会话；本目录面向更换AI模型后的接手。

## 当前最值得保留的结果

四板星型拓扑广播，48 bit自定义数据帧（32 bit测试数据＋16 bit校验），高速物理层帧头：

| 前导码长度 | 帧间隔设置 | 首次接收率 | 最终收到／应收 | 每批300条平均完整耗时 |
|---|---:|---:|---:|---:|
| 128 symbol | 0 μs | 100% | 10000／10000 | 48.259 ms |
| 64 symbol | 30 μs | 99.70% | 10000／10000 | 39.039 ms |

每批300条由三个实体叶节点重复承担时槽。两配置各有33个完整300条批次，均在100 ms内收齐；原记录另外含末批100条。实体硬件规模为一个中心、三个叶节点。0 μs为额外帧间隔设置，帧本身仍需发送时间。

数据与计时条件：[最新实验报告](records/outputs/min-gap-study-20261104-190134/最短帧间隔与星型广播实测报告.md) · [正式数据](records/outputs/min-gap-study-20261104-190134/正式测试记录.jsonl) · [逐组总记录](records/outputs/min-gap-study-20261104-190134/results.jsonl)。总记录包含调试失败和多个固件版本，当前正式结果以`正式测试记录.jsonl`为入口。
