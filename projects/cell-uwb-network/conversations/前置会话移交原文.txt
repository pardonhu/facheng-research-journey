## 一、项目背景与当前目标

用户是上海交通大学博士生，目前导师为**皮宜博老师**。当前科研方向是：

> 面向电池包内部的电芯级 UWB／蓝牙无线通信与感知，研究金属封闭、多径和遮挡环境下的可靠通信、电磁环境建模、自组织组网及通信感知结合。

需要区分：

- **电芯级**：无线节点下沉到单体电芯或与其直接对应的采集单元。
- **模组级**：多个电芯先通过本地有线采集，再由模组节点无线连接 BMU。
- **包级**：整包控制器与外部设备通信，不能等同于包内电芯组网。

研究不预设“电芯级一定更优”，需要评估节点数量、可靠性、时延、能耗、成本和部署复杂度。也不需要强行关联用户过去的 Neural Receiver／FastSET 工作。

已讨论的实验路线：

1. 主控烧录、日志验证。
2. SPI 读取 UWB 设备 ID。
3. 两节点简单收发，统计丢包和接收信号指标。
4. 三个及以上节点验证一发多收。
5. 增加调度、反馈、重传，再研究多节点上行和自组织协议。
6. 电磁场景从开放桌面开始，再逐步加入金属板、金属盒、模拟电芯排列；暂不直接在带电动力电池包内实验。

**当前仅执行第 2 步，不开展广播、测距或蓝牙协议栈集成。**

配置来源：

**以下 PCA10040 映射由仓库宏展开得出，尚未完成实物通断和波形验证：**

| UWB 信号 | 仓库宏 | Arduino 排针 | PCA10040／nRF52832 | 原 PCA10056／nRF52840 |
|---|---|---|---|---|
| SCK | `DW3000_CLK_Pin` | D13 | **P0.25** | P1.15 |
| MISO | `DW3000_MISO_Pin` | D12 | **P0.24** | P1.14 |
| MOSI | `DW3000_MOSI_Pin` | D11 | **P0.23** | P1.13 |
| CSn | `DW3000_CS_Pin` | D10 | **P0.22** | P1.12 |
| WAKEUP | `DW3000_WAKEUP_Pin` | D9 | **P0.20** | P1.11 |
| IRQ | `DW3000_IRQn_Pin` | D8 | **P0.19** | P1.10 |
| RSTn | `DW3000_RESET_Pin` | D7 | **P0.18** | P1.08 |

### 6.1 重要：与板载 LED 共用引脚

`pca10040.h` 中：

```text
LED1 = P0.17
LED2 = P0.18 → 与 UWB RSTn 共用
LED3 = P0.19 → 与 UWB IRQ 共用
LED4 = P0.20 → 与 UWB WAKEUP 共用
```

原 `Source/main.c` 调用了：

```c
bsp_board_init(BSP_INIT_LEDS | BSP_INIT_BUTTONS);
```

**建议最小识别程序取消全体 LED／按键初始化，避免先把 RSTn、IRQ 等配置成 LED 输出。**

同时必须认识到：取消软件 LED 初始化**不会移除实物 LED 电路的负载**。是否需要硬件隔离，要结合该板修订版原理图和实测决定，**不要直接剪线、切焊桥或假定必须改板**。

### 6.2 SPI 实例需要真正移植

[deca_spi.c](https://github.com/toolnail/UWB/blob/main/DW3_QM33_SDK_1.1.1/Drivers/API/Build_Platforms/nRF52840-DK/Source/platform/deca_spi.c) 当前主 SPI 使用：

```text
NRF_SPIM3
SPI3_INSTANCE_INDEX
SPI3_USE_EASY_DMA
NRFX_SPIM3_INST_IDX
慢速 4 MHz
快速 32 MHz
SPI Mode 0
MSB first
软件控制 CS
```

**nRF52832 不能照搬 SPIM3／32 MHz 配置。**

建议最小移植：

- 选 nRF52832 支持且未被占用的 SPIM 实例，例如 **SPIM0**。
- 同步调整 `sdk_config.h` 中 SPI／SPIM 实例使能，不能只改寄存器指针。
- 首轮把慢速和快速路径都限定到 **1 MHz**，确保调用“fastrate”也不会切回 32 MHz。
- 保持 Mode 0、MSB first、手动 CS。
- 审核缓冲区长度和 EasyDMA 单次传输限制；读 ID 只需短传输。

### 6.3 删除本任务不需要的第二套 SPI 初始化

原 `nrf52840_dk_spi_init()` 无条件调用 `spi2_init()`；`dw_irq_init()` 也初始化第二个 IRQ。

对单块 DWM3000EVB 的最小识别程序：

- 不需要 SDK 为其他芯片预留的第二条 SPI 路径。
- **应裁剪或条件禁用第二 SPI／第二 IRQ 初始化。**
- 不要因为选了 `TEST_READING_DEV_ID`，就以为这些初始化会自动消失。

### 6.4 复位与跳线

源码 `reset_DWIC()` 的做法是：

1. RSTn 输出低电平。
2. 等待 2 ms。
3. 切回输入、无上下拉，释放复位。
4. 再等待 2 ms。

**不要把释放复位改成推挽输出高电平。**

DWM3000EVB 的 **J1** 供电选择，官方文档为：

- **2–3 短接**：使用 Arduino 排针的 3V3 电源。
- **1–2 短接**：使用 EVB 板载 3V3 DC/DC。

这是 **UWB 扩展板 J1**，不是主控板的接口编号。必须按实物针号、供电路径和板卡版本检查，不能只凭“上／下”方向。[farnell.com](https://www.farnell.com/datasheets/4509028.pdf?utm_source=chatgpt.com)

当前未核对用户实物跳线、实际模块供电电压和是否存在历史改线；**这些是装板前的待检查项**。不需要纽扣电池。
