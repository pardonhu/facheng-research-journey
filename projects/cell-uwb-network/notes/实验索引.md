# 实验索引

**先查MinGap正式数据。** 其他版本用于历史对照、定位错误和复用实现。

| 阶段／目录 | 实验内容 | 使用方式 |
|---|---|---|
| `min-gap-study-20261104-190134` | 四板星型广播，48 bit帧，DMA、双缓冲、间隔扫描和补发 | 当前正式入口：`正式测试记录.jsonl`及报告；总JSONL含工程调试失败 |
| `raw48-study-20261104-174555` | 两板48 bit帧，逐条请求—回复，PHY与回复等待扫描 | 用于验证精简帧及重传；其中350 μs为请求后的回复等待 |
| `broadcast-tree-study` | 272 bit单条帧，树型两跳中继，轮询／广播定时回复 | 历史端到端对照；486／636 μs为起始间隔 |
| `four-board-study` | 272 bit帧，星型广播与轮询、间隔扫描 | 历史星型对照；72节点推算来自每组三节点重复流程 |
| `tree-end-to-end-study` | 电芯先交给中继，再逐条／合包转发到中心 | 包含实际叶节点采集，不同于预先存好十条数据 |
| `ble-matched-study` | 借鉴蓝牙参考方法的轮询及十条聚合 | 预先在发送板生成数据；不等于真实十叶节点采集，也不是同学蓝牙代码完全复刻 |
| `preamble-study` | 不同前导码、数据量与重传 | 历史格式含额外字段，不能作为最新极简帧的收益 |
| `reliable-runs` | 缺包反馈、重传、确认丢失与去重 | 复用可靠传输思路，不把两板可靠性等同于300节点整轮成功率 |
| `capacity-study`、`gap-runs`、`broadcast-runs`等 | 较早连续发送、间隔及容量探索 | 参数与统计定义以各原记录为准 |

上述目录都位于[records/outputs](../records/outputs/)。原文件清单和哈希位于[provenance](../provenance/源文件清单.json)。

## 论文／厂家资料入口

- [DW3000数据手册](https://www.mouser.com/catalog/specsheets/Qorvo_DW3000.pdf)：物理层帧格式、符号时长、信道5／9和纠错编码。
- [Qorvo驱动指南](https://forum.qorvo.com/uploads/short-url/xD3TlXKvkujjdUaJWXv2b4E7GQN.pdf)：配置与定时发送接口。工程实际驱动仍以固定上游提交为准。
- [厂家标准数据帧示例](https://github.com/toolnail/UWB/blob/79209d263fc536fbffd4c5af5b2e4c4b610eeedb/DW3_QM33_SDK_1.1.1/Drivers/API/Src/examples/ex_07a_ack_data_tx/ack_data_tx.c)：常规短地址帧参考。
- [同频并发UWB研究](https://www.carloalbertoboano.com/documents/schuh24complex.pdf)：用于后续文献调研；论文中的多链路并发不代表一颗本机芯片能同时解码多个频率信道。
