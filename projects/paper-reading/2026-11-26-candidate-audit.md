# 三条研究候选的近邻核验与最小验证

2026-11-26。方向覆盖 FastSET 在线适应、无线调度和射频场景建模。此次重新检查了具体方法、观测条件和实验对照，结论是：**三条问题都有可检查的依据，当前提出的解决办法尚未通过独立贡献审查，未完成“三个过关的新选题”的目标。** 下面保留问题、已被覆盖的做法和下一步的判断实验。它们是助手的研究分析，尚未成为作者确定的博士选题。

## 1 在线适应怎样知道一次更新会改善接收

<a id="idea-07"></a>

设接收机刚进入一个新环境，只有几个数据块的时间调整模型。前端的导频拟合误差下降，后端交付的正确比特却可能减少。这里需要分开两个原因：训练标签本身含有输入噪声；相同导频还容许不同信道解释。前者已有直接修法，后者是否在真实编码链路中留下额外困难，需要先验证。

### 最接近的工作和已覆盖内容

[FastSET 公开会议版](https://pardonhu.github.io/assets/papers/fastset.pdf) §IV-B 式(12)–(14)把接收网格放进估计器输入，以同网格上的 LS 导频估计作为监督。这个公式关系支持检查同源噪声的影响；当前期刊稿和代码是否仍使用相同目标、最终 BER 是否因此受损，本次没有测量。

[Luostari 等的 OTA 研究](https://arxiv.org/pdf/2608.12918v2) §IV–V直接分析标签 Y/x=H+n/x 与输入 Y 共享噪声，并用独立噪声与相关噪声的受控比较解释性能差异。[Self-Supervised Operator Learning for FAS](https://arxiv.org/pdf/2611.25756) §IV 式(7)–(10)已结合导频拆分和已知噪声方差的 SURE 修正。[Ridge A-MMSE](https://arxiv.org/pdf/2608.15945) §II–V则约束输出滤波矩阵，并从带噪全网格样本构造收缩教师。因此，“给 FastSET 接入无标签去噪”本身没有形成新贡献。

更直接的对照是 [Teng 与 Chen，JETCAS 2020](https://access.ee.ntu.edu.tw/files/journals/2020%20JETCAS%20%28Syndrome%20Loss%29.pdf)。Algorithm 2冻结 BP 解码器，仅把校验约束的损失传回前端均衡器；Fig.8–9同时比较 BLER 和 MSE，已展示两种目标的最优结果不同。它还考察同信道可用块数减少的情况。因此，“冻结后端、按最终解码效果训练前端”也已有方法。

### 本轮推演及其含义

原创复算 [ota_supervision_counterexample.py](experiments/2026-11-26-candidate-audit/ota_supervision_counterexample.py) 用 H 与噪声方差均为1的复高斯模型，只学习一个缩放系数。同包标签使系数等于1、测试真实信道 MSE约1.000；已知方差 SURE 得到系数约0.499、MSE约0.499，接近解析最优。这个例子同时验证了噪声复制风险和现成方法的有效性，未运行 FastSET。

另一个原创 [pilot_ambiguity_counterexample.py](experiments/2026-11-26-candidate-audit/pilot_ambiguity_counterexample.py) 使用8个子载波、导频位置0和4。两个三抽头信道分别为 [1,0,0] 和 [0,0,1]；配上相应的 QPSK 数据旋转后，导频与整个接收网格相同。在子载波2，真实符号分别为+1和−1，零 logit处的比特损失梯度方向相反。补一个该位置的已知符号可以分开两种解释。这个构造省略了编码约束，不能直接推定真实接收机存在相同歧义。

### 还缺哪项突破，第一步怎样验证

剩余假设是：**在很短的适应窗口内，优先取得能确定有效更新方向的观测，可能比继续拟合已有导频更划算。** 可利用的结构是导频算子的零空间、星座与码约束，以及冻结后端对前端扰动的敏感方向。当前尚缺一种比普通任务导向导频或信息增益选择更有效的具体构造；这个缺口不能用“加入主动学习”代替。

第一步只安排回放诊断：从同一个 checkpoint、相同接收块和能量预算出发，比较无更新、原目标、mask+SURE、收缩、固定后端 syndrome 更新。记录导频损失和独立测试块 BLER 的成对变化；先检查码约束是否已排除上面的歧义。对仍有更新分歧的样本，枚举允许的一次补测，求可达到的收益上界，扣除补测与计算时间。若这个上界都没有净收益，停止设计新选择算法。该回放实验尚未执行。

**状态：保留为 FastSET 的具体诊断问题，未推荐为新论文章节。** 把现成修法接到 FastSET 上的版本已淘汰。

## 2 换了调度以后，旧日志里的网络还存在吗

<a id="idea-08"></a>

设中心要按期限收齐一批传感器记录。旧策略下，节点B因节点A占用信道而等待；新策略让B先发，A和B随后积压多少、何时重试都会变化。若把旧吞吐和等待曲线原样放进新策略仿真，比较的环境里就保留了旧策略造成的状态。这是适用于组网的研究问题；当前归档的电芯UWB使用集中时槽，不能未经测量就声称它存在CSMA退避。

### 最接近的工作和具体限制

[CausalSim，NSDI 2023](https://www.usenix.org/system/files/nsdi23-alomar.pdf) §2–5已处理动作影响测得吞吐的偏差。它学习潜在因素和轨迹生成关系，超出了原样回放。§3.1（PDF pp.6–7）明确要求潜在环境不受动作影响，并以改变路由为失效例。多轮调度若持续改变未记录的竞争队列或退避状态，就要将这些量纳入受动作驱动的状态，而不能沿用外生环境假设。

[CV-CCI](https://arxiv.org/abs/2609.05073) §II、§IV、§V已结合大量观察日志和少量随机数据，给无线调度的反事实KPI区间；其决策样本独立、两种采集机制共享上下文分布。[H-SCM](https://arxiv.org/abs/2611.00635) §III–IV使用跨层结构方程，单个epoch内固定负载及用户条件。两者都覆盖了“因果模型加随机校准”的宽泛设想。

继续追到基础方法，[Kallus 与 Zhou，NeurIPS 2020](https://proceedings.neurips.cc/paper_files/paper/2020/file/fd4f21f2556dad0ea8b7a5c04eabebda-Paper.pdf) §3–4已经为隐藏混杂给出策略价值的部分识别上下界；[Becker 与 Fidler](https://arxiv.org/abs/1506.04657) §III-C–D已用队列守恒、最小探测和结束时积压估计非平稳服务界。因此，增加预测区间、短探测或守恒约束，也不能单独充当突破。

### 剩余结构与首实验

一个具体线索是共享介质产生的**联合状态约束**。一次被两个节点共同听到的发送，会同时冻结它们的退避倒计时；逐链路独立取最坏情况会包含物理上不能同时发生的组合。候选需要从允许导出的时间戳、ACK和忙闲记录中恢复这类约束，再在新策略下传播兼容状态集合，计算整批完成时间范围。

标准CSMA仿真已包含倒计时冻结；普通动态系统识别、HMM和被动干扰推断也是强基线。方法贡献必须落在：受限日志下新获得了什么可辨识关系，或在相同信息下怎样得到更紧且可计算的期限界。仅把标准协议写进隐状态模型仍未达到要求。

进一步全文阅读的 [Deconstructing Interference Relations in WiFi Networks，SECON 2010](https://raw.githubusercontent.com/Wings-Lab/Wings-lab-webpage/master/pdfs/2010-secon.pdf) 已有两节点联合11状态HMM，区分空闲、退避、延迟和发送。§IV-A（p.5）过滤第三节点报文；p.9讨论增加节点带来的状态增长。它没有显式记录剩余整数退避计数和完整队列，最终主要估计deferral/collision关系。故联合隐状态建模也已有直接无线近邻。

本轮核对的协议小例是：C发送期间A、B都被迫等待，两套剩余退避分别为(1,3)与(3,1)，截至C结束的包级历史相同。恢复竞争、每次发送服务占10槽时，A的完成时刻分别为11与23槽；A的期限取15槽就得到不同结果。两套状态的全批收齐时间都是23槽，该例只支持指定节点期限的区别。扩状态HMM可以保留两种可能，已知随机规律时也能估计期限概率。尚可研究“共同空闲时钟与相对计数差”能否压缩这种联合状态，并在非团拓扑、漏包和重置时保持有效界；当前没有优于完整HMM或粒子滤波的结果。

本轮已执行一个更小的[联合状态反例](experiments/2026-11-26-candidate-audit/hidden_joint_counterexample.py)：机制A让两条链路一起好或一起坏，机制B让它们轮流好，各状态概率均为一半。旧策略每轮只试一条链路，因此动作与ACK的全部历史分布相同；新策略要求同轮两条都成功，完成率却分别为1/2和0。完整枚举得到旧观测总变差为0。这个例子只证明单动作日志缺少联合信息，不包含长期队列反馈。普通联合HMM也无法凭相同旧日志决定哪个机制为真；额外观测必须明确写入方案，并向所有基线同样开放。

第一步用三节点、一个共同忙信道事件，固定到达序列和信道，比较独立服务界、共同事件约束界、普通历史模型及全状态仿真。模型只看相同日志，全状态只作为裁判；以留出策略的整批完成时间、区间覆盖和宽度判断。若共同事件必须读取芯片不可导出的内部状态才能确认，或普通灰箱模型已给相同结果，该版本停止。这个三节点反事实实验尚未执行。

**状态：多轮隐藏状态问题保留；宽泛因果回放方案淘汰，独立机制尚缺。**

## 3 拟合良好的射频模型，什么时候足以决定波束

<a id="idea-04-followup"></a>

这一项推进[昨天的 I04](2026-11-25.md#idea-04)，不另起名字计作新点子。场景是用少量测量标定厂房的射频模型，再预测未测节点应选哪个波束。两个模型都能解释现有测量，仍可能对下一处位置给出相反选择。

[RFDT](https://xyzhang.ucsd.edu/papers/Xingyu.Chen_MobiCom26_RFDT.pdf) §4、§5.2（PDF pp.7–8）已说明相位整周歧义，并用平滑代理逐步回到精确信号模型改善优化；[PEAC](https://arxiv.org/pdf/2312.12625) §III–IV已建模局部路径相位误差。[Electromagnetic Twin](https://arxiv.org/html/2609.27895v1) §VII已用局部信息矩阵选择下一次测量。因此，“保留多个解释，再主动测量”须与完整多模态推断、任务导向测量和固定空间多样性比较。

### 本轮新增的随机布局检查

原创 [rf_alias_random_check.py](experiments/2026-11-26-candidate-audit/rf_alias_random_check.py)固定种子，预先生成400组单反射面位置、两个独立标定位置和一个目标位置。两个候选场景材料相同；每个快照固定总能量，并拟合公共复增益。按解析路长整数分支构造替代场景，检查其标定均值距离及目标波束差异。

| 标定配置 | 存在近观测且目标错误波束损失超过3 dB的布局数 | 固定在首个标定点横移0.5 m补一包后，仍满足近观测条件的布局数 |
| --- | ---: | ---: |
| 2天线、20 MHz | 10 / 400 | 0 |
| 2天线、80 MHz | 10 / 400 | 0 |
| 2天线、320 MHz | 0 / 400 | 0 |
| 8天线、20 MHz | 1 / 400 | 0 |

“近观测”在脚本中定义为两个快照联合均值距离小于2σ；它不是估计错误概率。替代场景利用真值作存在性构造，未运行RFDT估计器。补测增加一个快照，两种模型的真值和候选参数不作为实际算法输入。这些数值不代表真实场景的发生率。

结果增加了对问题存在的支持，也削弱了当前方法提案：固定空间多样性已分开本轮找到的全部有害别名，尚无引入复杂主动选点的收益依据。原先“多模型加智能补测”的版本停止推荐。

如继续研究，新增机制应能利用反射路径的整数分支结构，减少检查所有模型的计算，同时可靠发现会反转目标动作的分支。第一步应在多个未知反射面、固定可用测点和多目标查询下，与完整后验、普通多初值及固定补点比较；同时计入移动、导频和计算成本。只有同等误选风险下出现明确收益，才推进算法。当前还缺这个结果。

**状态：问题证例保留；现有主动补测版本未过强基线，暂不推荐立项。**

## 额外淘汰的感知版本

<a id="idea-09"></a>

还检查了“异步节点双向测量消时钟，再用稀疏测量图恢复目标距离”。[Reciprocal Range-Doppler Estimation](https://arxiv.org/html/2611.30221v1)式(3)、(23)–(25)已用正反半和恢复物理量，并处理部分路径匹配；[AsyMov](https://arxiv.org/html/2412.10387v4)已利用路径间公共时钟项和静态散射方向。

当每条边给出 d_i+d_j，连通偶环保留一个交替零空间，奇环可消除该距离变量中的自由度；这是无符号关联矩阵的已知性质。进一步加入节点硬件群延迟 h_i 后，边量变成 (d_i+h_i)+(d_j+h_j)。即使图完整，变换 d_i→d_i+a_i、h_i→h_i−a_i 仍不改变观测。已知节点几何和多目标约束可能提供额外信息，不能由独立距离的零空间直接判断完整定位失败。

因此，已关联、已校准的基础版本淘汰。未知目标关联和未知硬件延迟的系统版本仍须与联合几何校准及多目标匹配比较，尚无过关方案。本轮未取得ChirpEye正文，只核实了元数据，未将其纳入精读或用摘要裁定其能力。

## 这些结果怎样帮助后续科研

FastSET线索可直接形成一次监督目标诊断，现成方法作为对照；无线调度线索明确了回放实验需要演化哪些状态；射频建模线索说明简单补测应先于复杂主动算法接受比较。当前执行了原创低成本统计和代数检查，没有重启硬件、训练已有模型或修改用户论文。

本轮实际阅读包括：FastSET公开版相关模型，OTA标签研究、SURE-FAS与Ridge A-MMSE的方法和实验，JETCAS均衡器算法与Fig.8–10，NetLLM正文与附录，CausalSim方法与主要实验，CV-CCI和H-SCM相关模型及实验，部分识别OPE与服务曲线的直接相关推导，RFDT与PEAC相关方法，以及互易感知与AsyMov的观测模型。不同论文的完整阅读范围不相同，未声明复现这些系统。

研究判断按上述近邻与复算结果保存。后续AI应从尚未回答的实验问题继续，保留淘汰状态；已有工具的组合和未验证的机制不能改写成作者已经确定的新贡献。
