# 2026-11-27：在线接收机升级之后，怎样重新使用尚未解出的旧包

**2026-11-28后续判断：** [直接近邻与期限检查](2026-11-28-wireless.md#i10-followup)表明，新信息到来后重处理旧HARQ观测已有技术流程。撤回这一贡献表述；投影与残差界保留为数学检查，缓存更新准入仍需胜过同预算迭代接收机。下文保留11月27日形成过程。

日期：2026-11-27。状态：可做首轮测量的研究候选，尚未证明有系统收益；此前 CFO 排布、虚拟 puncture 两项不作为通过候选。本文只写公开论文、原创推导与拟议实验。

## 用一个场景说清楚

基站收到一个包，第一次没有解出来，保存软信息，等重传时合并。等待期间 FastSET 已经更新了接收机。新的接收机可能更会处理阵列误差或干扰，能够从同一个旧包里读出过去漏掉的证据。通常的 HARQ 缓冲只留下旧模型算出的 LLR；删掉的原始观测方向再也拿不回来。

想研究的是：**能否只保留“未来几次模型更新可能还要用到的观测”，让新模型重新解释旧包，同时给出这次重解释误差有多大的可计算界？** 缓冲保存的是可供修订的证据。模型更新范围和保留的证据共同决定该轮能否重算。

这项问题贴近 FastSET 的在线适应、接收机模块接口和端到端吞吐；不直接服务三叶节点 UWB 的现有固件。FastSET 当前实际 HARQ 支持、码率与硬件可用数据还须确认；首实验可在现有离线 I/Q 和链路仿真中完成。

**关键事实条件**：版本不同本身不妨碍相加。各轮都是校准的独立似然时，常规软合并就能工作。需要先测到“旧证据中有可挽回的接收损失”，这项问题才有投入价值。当前信道 h 的改善也不等于旧时刻 h 的改善；重算必须使用旧轮导频及元数据重新估计旧 h，不能把当前 h 直接套给旧 y。

## 最接近的方法做到哪里

1. [HARQ Buffer Management: An Information-Theoretic View](https://arxiv.org/abs/1501.06166)，IEEE TCOM 2015，DOI 10.1109/TCOMM.2015.2472015。实际读 §II、§VI、§VIII 对应基带/LLR 比较及 MIMO 实验。它已比较基带与 LLR 压缩；§VI 式(45)–(50)按已知每轮信道做变换编码，并用特征值分配压缩精度。§VIII Fig.7–8/10讨论不同表示、天线数下吞吐。该文的 H 已知，MIMO 推导采用高斯输入和长块。**保存投影、按照信道选择方向、比旧 LLR 保存更多信息，都已有直接先例。** 新增问题须落实为未来模型修订所需信息及更新准入，不能把变换编码本身当贡献。

2. [Deep Log-Likelihood Ratio Quantization](https://www.eurasip.org/Proceedings/Eusipco/eusipco2019/Proceedings/papers/1570533405.pdf)，EUSIPCO 2019，DOI 10.23919/EUSIPCO.2019.8902805。全文5页已读。§II 式(4)指出已知 SISO 信道时，瞬时 SNR 和均衡观测的实虚部三个实数足以恢复 LLR；§III 用三维 autoencoder 做量化；§IV-C 把第一轮恢复出的 LLR 与第二轮 LLR 相加，实验采用两次有重叠的码字传输。它恢复的是既有解调判定，未解决未来更改接收规则后缺失的观测方向。其2019会议版Fig.4给出的15比特表示对32比特标量量化比较为约2.13倍，不能误写后续版本或摘要中的更高数值。

3. [EQ-Net](https://link.springer.com/article/10.1186/s13638-022-02129-z)，EURASIP JWCN 2022，DOI 10.1186/s13638-022-02129-z。实际读官方 HTML §2.1–2.6、§3.2–3.7；PDF下载结果为验证页，未据此声称读PDF。它先学习软比特压缩表示，再训练接收观测和 CSI 到该表示的映射。实验同时比较估计、量化、信道迁移及 CSI 扰动。它已有共享低维表示、分阶段训练和跨估计器量化；没有必要再提“学一个latent保存旧LLR”。其固定软比特恢复目标与本候选的多版本可重解释目标不同。作者代码：[utcsilab/eq-net](https://github.com/utcsilab/eq-net)。

4. [AURA: Online Learning via Learned Latent Bayesian Tracking](https://arxiv.org/abs/2609.31559)，作者标注 NeurIPS 2026 接受。读 §4.1–4.2、附录 C.1、D.1.3、E、F。用离线学习的低维参数轨迹和在线 EKF 更新接收器；OTA 中 CNN equalizer 后接解析 demapper。它是本候选限制适应族时必须比较的强工具。参数 latent 小不推出历史 I/Q 的所需统计量也小；两种压缩针对不同对象。OTA 表9中1.8K参数CNN的适应为10.573 ms，不能称为亚毫秒更新。代码：[AURA-Receiver](https://github.com/aura-online-adaptation/AURA-Receiver)。

5. [Robust and Efficient Distributed Compression for Cloud Radio Access Networks](https://arxiv.org/abs/1206.3602)，IEEE TVT 2013。读 §IV、§VI-B；PDF字形映射恢复后正文可读，未声称完整核验公式证明。该文已用有界协方差不确定集做最坏情况压缩优化，模拟显示优于把错误协方差当真值。**“考虑不确定性做鲁棒压缩”也已有。** 本候选要证明逐轮观测残差给出的重解释误差界和 HARQ 更新接口能带来它没有针对的收益；不能只把统计不确定集合换成模型参数集合。

## 拟议的具体构造

先从可分析的子问题起步：每轮多天线观测 y=H x+n，白噪声方差 σ²；神经网络更新的是“由该轮导频及元数据得到 H”的规则，demapper 为已校准的高斯似然。对同时任意更新的非线性 FastSET demapper，本构造还不适用。必须测量这个限制损失多少适应能力。

1. **选更新方向包络。** 在独立校准轨迹上收集旧、新模型对同一批历史导频的 H 估计；选择 r 维正交基 U，覆盖可能被修订的接收方向。初版可用所有版本 H 的拼接 SVD；再比较按历史重算损失选方向的办法。SVD 只是起点，不能声称算法创新。参数 latent 不作为 r 的替代指标。
2. **每次未解出时保存可重算证据。** 保存 z=Uᴴy、残差范数 e=||(I−UUᴴ)y||，以及本轮导频、噪声估计、调制、资源映射和基编号。计入这些元数据。旧基永远不能事后补出删掉的方向；新的基只用于新接收包。
3. **用新模型重读该轮导频。** 得到 H_new。若 H_new=UC，则所有符号候选的关键项 H_newᴴy=Cᴴz 可恢复，候选间似然比与完整 y 重算一致。这里是精确的线性代数恒等式，未使用 Taylor 展开。
4. **给超出包络的更新一个数值误差界。** 令 H_perp=(I−UUᴴ)H_new。对候选符号 x，漏掉的交叉项满足 |Δscore(x)|≤2e||H_perp x||/σ²。保留完整可计算的 ||H_new x||² 项；两个比特集合的 log-sum-exp 各自用最大候选误差定界，可推出 LLR 区间。量化 z、U、e 后需再叠加量化界，向上量化 e 才能继续作上界。
5. **更新与缓冲逐轮协商。** 区间小的历史轮重新解释，区间大的轮继续保留原证据或按process冻结。只有低开销误差界无法支撑时才保留更多原始证据。该界约束 LLR 数值误差，尚不等于 LDPC 解码或 BLER 保证。CRC 成功只证明当前译码输出通过校验，不能倒过来证明区间一定正确。

可能的独立机制在第4–5步：一个更新是否能作用于某个尚未完成的传输，由这轮实际保存的信息和可计算的漏失证据共同决定。需要联合决定缓冲表示与模型更新范围，而不是一律等所有HARQ完成或一律重跑全部 I/Q。高斯近似失配、前端非线性及动态干扰协方差会限制上述保证；有色噪声可在固定已知白化后推导，白化矩阵也更新时需扩充方向族。

## 已经运行的小核验

[harq_update_audit.py](experiments/2026-11-27-candidate-audit/harq_update_audit.py) 与 [JSON](experiments/2026-11-27-candidate-audit/harq_update_audit.json) 仅验证代数和存储算术，没有神经训练、LDPC、CRC 或硬件实验。

- 8维复观测，2维固定U，12个包络内H，1,000个观测：完整输入与投影重算BPSK LLR最大差约1.24×10^-14。
- 两个观测(1,1)、(1,−1)经旧h=(1,0)都得到LLR=4；新h=(1,1)/√2下分别为5.657和0。因此只给旧LLR做一个标量变换无法重建两种新证据。
- 单参数族v(t)=(1,t,…,t^7)在8个不同t上张满8维：一维更新参数也可能需要保存全部输入方向。
- 新h超出U时，1,000个随机样本的BPSK残差界无违反；这是公式程序一致性核验。
- 8Rx、1流64-QAM、1,024数据符号、64导频、每实数8位、LLR每比特6位：旧LLR为36 bit/数据符号；全I/Q含导频为136；r=2投影含导频和基的小计约40.5；r=4小计为73。上述投影小计尚未计逐符号残差范数e；若e用8位，分别再加8得到48.5与81。还未计头部、噪声/CSI元数据、量化比例和工作空间，因此均不能称总缓存，也未验证相同误码。r升高会迅速吃掉优势。

## 第一步验证：先判断问题规模，再优化压缩

固定一份真实或现有信道生成器输出的 I/Q 轨迹，保留每轮独立导频，回放至少两轮 HARQ。使用同一物理轨迹、编码、重传次数、更新数据及模型权重，做以下基线：

| 基线 | 回答的问题 |
|---|---|
| 每process绑定模型版本，到完成才切换 | 等待是否已经足够便宜；统计实际等待和并存版本内存 |
| 新旧模型直接混合LLR，按MCS/SNR/版本做校准 | 是否仅为可用温度/可靠度校准解决的问题 |
| 保存低比特全I/Q与导频，全部历史重跑 | 可实现的强上界与最简单替代；比较真实总内存和重算耗时 |
| 已知/估计CSI的2015变换压缩、鲁棒CRAN压缩 | 新增机制是否超出已有信号方向选择与不确定性优化 |
| LLR标量量化、DeepLLRQ/EQ-Net | 同一存储预算内的传统软缓冲与学习压缩 |
| 只改接收器、不改缓冲；只改缓冲、不在线更新 | 收益来自哪一步 |

阶段0首先比较“完整历史重跑”与“process冻结/校准合并”。用既有FastSET更新前后checkpoint，分别记录各旧包重算的提升和恶化。物理信道变化、硬件误差变化、纯模型版本变化分别测试。若全I/Q重跑也没有足够收益，后续压缩研究停止。

阶段1才比较r=1、2、4、8的方向包络，原型先用解析重放及量化，不训练新大网络。度量每比特LLR误差、译码BLER、重传数、端到端goodput、尾时延、每未完成传输总缓存、重放算力。另测最坏误差界的松紧；若它对几乎所有更新都要求冻结，就没有接口价值。AURA/受限前端与完整FastSET的适应差距也必须单列。

预先约定的淘汰条件：①完整重算与最佳简单基线在配对置信区间内无收益；②收益仅来自LLR缩放或更强信道估计，已有校准/接收器能获取；③包络秩接近原输入维度，低比特全I/Q更便宜；④少量低维更新无法保留FastSET的主要适应收益；⑤短HARQ周期下process冻结的延迟和资源成本可忽略；⑥鲁棒误差界需要宽到失去可用性。建议把“goodput至少改善5%或在同BLER下总缓存至少减半”作为本次立项筛选门槛，这个数值是拟议决策门槛，不是已有结果。

## 可带入论文的写法

这项工作如果实验支持，实验顺序应是“旧包还有多少能挽回的证据→最简单基线为何不够→压缩后留下多少→迁移误差界是否可用→系统总收益”。每段开头先给读者一个可验证的问题，接着交代配对条件，结果后区分观测和机制解释，最后限定到已测更新族。

原创自拟差例："Our new receiver is better and therefore we recompute old packets. The compact cache saves memory and increases throughput."

诊断：把当前包改善外推到历史包；省略旧时刻CSI；没有对照process冻结；没有实际总内存；将待测机制写成结果。

原创英文实验开头："We first test whether a receiver update can recover useful information from an unfinished HARQ transmission. For each recorded transmission, we retain its own pilots and compare the original soft output with a replay under the updated receiver. We then measure how much of this replay gain survives when the payload observations are projected onto a fixed buffer subspace. All methods use the same received samples, receiver checkpoints, and retransmission schedule; buffer costs include pilots and projection metadata."

这段只表达拟议实验，不填造结果。图可分三列：左列同一旧包经旧/新模型的配对结果；中列缓存大小—重放损失曲线；右列端到端goodput—总缓存。正文引图后解释哪些旧包被改善或恶化，再用“仅当前h替换旧h”消融展示错误归因。

## 本轮判断

本候选保留为**有明确构造、可证伪的研究问题**。已知工具与压缩基础很强；现在最缺的证据是实际FastSET更新下历史重放收益和低秩更新包络。候选的贡献不能写成“首次低维HARQ压缩”或“首次处理LLR不匹配”。若阶段0失败，应关闭该方向。

同轮曾考虑“每个资源元素排除自身证据后构建channel posterior，固定解析demapper”：Badiu等[BP/MF/EP 2012](https://arxiv.org/abs/1202.1467)已给出cavity消息和不确定性处理，未保留为候选。EXT-GEPNet亦已有extrinsic训练；这里只作检索线索，未完整读透其方法实验。
