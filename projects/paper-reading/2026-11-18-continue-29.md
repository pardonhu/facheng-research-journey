## TimeXer

Yuxuan Wang、Haixu Wu、Jiaxiang Dong、Guo Qin、Haoran Zhang、Yong Liu、Yunzhong Qiu、Jianmin Wang、Mingsheng Long，**TimeXer: Empowering Transformers for Time Series Forecasting with Exogenous Variables**，NeurIPS 2024 主会，DOI [10.52202/079017-0015](https://doi.org/10.52202/079017-0015)。[会方题录](https://proceedings.neurips.cc/paper_files/paper/2024/hash/0113ef4642264adc2e6924a3cbbdf532-Abstract-Conference.html)；[正式全文](https://proceedings.neurips.cc/paper_files/paper/2024/file/0113ef4642264adc2e6924a3cbbdf532-Paper-Conference.pdf)；[作者工具](https://github.com/thuml/TimeXer)。

### 六项研究卡片

**问题。** 预测某一序列时，其他传感器可以提供信息，但这些辅助变量本身未必需要预测；电价预测是作者的主要实例（§1、§3，pp.1–4）。**缺口。** 把所有变量同等处理会引入额外交互，而只看目标历史会丢失外部信息；逐时刻直接拼接还要求两路记录对齐。**观察。** 目标序列需要细看局部时间变化，外部序列可以先概括为每变量一个表示，再按当前目标状态读取（§3，pp.4–5）。**方法。** 目标历史形成多个 patch token 和一个可学习全局 token；目标内部做自注意力，全局 token 再对外部变量 token 做交叉注意力，最终只预测目标未来值（图2、式2–8）。**证据。** 五个电价数据集上，以168小时历史预测24小时，表5的平均标准化 MSE 从完整输入的0.307增至外部历史置零时0.330、目标历史置零时1.125，说明两路信息的作用大小不同（§4.3.1，pp.8–9）。**边界。** 这些预测和输入替换实验支持信息利用方式；模型中的注意力权重不直接给出物理因果关系，整个外部序列替换也不同于随机丢失几个采样点。

### 工具怎么工作，为什么选这两项学习重点

第一项是**先定义信息角色，再设计表示粒度**。§3先给出目标历史 $x_{1:T}$、外部历史 $z_{1:T_{ex}}$ 和未来目标 $\hat x_{T+1:T+S}$，随后逐项解释两种 embedding。对目标序列，patch 保留局部变化；对每条外部序列，线性投影得到一个变量 token。一个目标全局 token 汇总目标历史，再查询外部变量。下一层的目标自注意力可继续把这部分信息传给 patch；最终输出头同时使用 patch 和全局 token，因此单层模型也可以从全局 token 获得外部信息。该读法与代码 `EncoderLayer.forward` 的先自注意力、后更新最后一个 token 的顺序一致。

这个思路可用于固定参考链路的偏差预测：校准得到的测距偏差是目标，接收机温度、供电和近期通信负载是候选辅助观测。输出仍然只有下一段偏差预测，研究者无须为了使用温度而同时优化温度预测任务。外部观测必须在预测时刻已经到达；作者附录H.1讨论的未来外部信息是已获得的外部预测值，不能换成事后测到的未来真值。

第二项是**用实验顺序说明辅助信息到底做了什么**。这比笼统报告“融合后精度更高”更适合组网写作：读者可以跟着控制条件，区分多看历史、读到有用外部变量、保住目标自身历史这三件事。

### 原创可复算例：相同目标历史，为什么仍值得读外部观测

以下是说明信息作用的假设模型，未运行 TimeXer，也不是用户测试台结果。固定参考距离已知，最近两次校准残差均为0 m。设下一时段的残差受当前已测温度 $T$ 影响，规律人为设为 $b=0.04(T-25)$ m。两个等概率场景分别为20°C和30°C，因此未来偏差为−0.2 m和0.2 m。只读相同残差历史的确定性预测器必须给出相同预测；在这个对称例子中，最小平均平方误差的常数为0，其 MSE 为 $(0.2^2+0.2^2)/2=0.04\ \mathrm{m}^2$。读到当前温度且已学得这条假设规律的预测器可区分两种场景，理想无噪声误差为0。

这说明外部信息能解除“目标历史相同”的歧义，未证明温度在实际设备上具有这一线性效应。温度值若只有过期读数，仍需记录时间戳、到达时间和保持时长；不能把新温度事后填回预测输入。目标残差历史也只有在参考距离或其他独立标注可得时才能形成。

还可以手算表示选择的一个局部成本：4个目标 patch、1个全局 token、6个外部变量 token，单头自注意力与交叉注意力的分数项分别为 $5^2$ 和6，总计31；把全部11个 token 放进一次全连接自注意力则为121。这个计算只比较注意力分数项，未计投影、前馈层、训练反传或硬件时延，不能写成整体加速3.9倍。

### 原创英文训练：让实验问题带出对照，再解释结果

下面两段由助手为本次练习创作，不是论文原文或用户现稿。

**差段。** “Our forecasting model understands all external factors and remains accurate when sensor data are missing. We concatenate the measurements and use attention to identify causal variables. The results are good because the model learns more information. Therefore, the same design can predict ranging errors on new devices.”

**诊断。** 前两句没有说明预测目标、缺失操作和外部信息何时可用；后两句把相关性、误差变化和跨设备适用性合成一个未检验结论。读者无法据此重建实验。

The predictor retains a patch-level history of the residuals and reads the available temperature history through a separate context representation. To isolate the contribution of this context, the evaluation compares the complete input with zero-filled and time-shuffled temperature histories while keeping the residual windows, training budget, and test episodes fixed. A separate condition removes the residual history to determine how much the forecast depends on the target's own observations. These comparisons distinguish useful temperature information from the benefit of retaining a dedicated residual pathway. The experiment reports prediction error at each forecast horizon and the age of the newest temperature sample; transfer to another receiver is evaluated on held-out devices.”

**为什么这样改。** 段首提出辅助观测是否提供新增信息，第二句把信息分工变成具体处理，随后按“移除辅助内容—移除目标内容”的顺序组织对照，最后交代读图所需的预测跨度和观测年龄。这里的时间打乱、固定训练预算和跨设备留出均为原创实验设计，不能归到作者表5。

Error bars show variation across receiver episodes.” 这是一张待做实验的图注设计，当前没有相应实测曲线；它把固定条件、横轴含义、比较组和误差条统计单位放在同一处，读者不必回正文猜图。

**适用条件与下一步决策。** 新问题是：参考链路的校准间隔拉长后，低成本温度历史能否降低两次校准之间的偏差预测误差？最小实验保留目标历史模型、目标加温度模型、温度时间打乱模型三组，并按设备、采集日期划分训练测试，分别报告米单位误差和每次校准的能耗。若辅助观测只在同设备同日期有效，应先检查设备专属关系与采样时刻；若稳定降低新设备误差，再研究减少校准次数。该问题建立在当前收集流程已经完成的基础上，新增的是校准预算条件。

这是复读。旧笔记讨论稀疏网络的供需约束和地理路由的可达条件；本次聚焦 §6.2 的故障修复与 §6.3 的局部绕行，追踪两组时延到底结束于什么事件。

### 六句研究卡片

- **问题：** 稀疏卫星网络中，链路故障既可能留下替代路径，也可能使局部拓扑断开，两种情况需要不同恢复动作（§4.3、§6.3）。
- **缺口：** 等待远端控制器统一修复会引入往返时延，而把所有恢复都交给本地节点又无法凭空生成已经不存在的可用连接（§4.2–4.3）。
- **观察：** 一个地理区域可以由不同卫星承担转发，稳定的地理目标与当前执行节点可以分离；替代路径尚存时，本地可以先继续转发（图11、§4.3，p.8）。
- **方法：** 数据包携带地理分段目标，本地优先使用可达下一区域的链路，否则沿区域内环转交；环被故障断开时缓存，控制器寻找替代连接并修复拓扑（§4.3）。
- **证据：** 1741个虚拟卫星的分组级实验中，1000次随机链路故障的控制修复平均83.8 ms，其中报告与指令往返平均83.5 ms；保持连通的故障情形下，作者另报本地重路由延迟13.6–44.3 ms（§6.2–6.3，pp.10–12，图17d、19d）。
- **范围：** 虚拟化与硬件在环测试验证所建模网络；断连后的缓存和最终转发仍依赖可修复连接、缓存容量及后续服务机会，文中这些均值不构成任意故障下的交付期限保证。

### 重点一：用前一实验的剩余等待引出下一条处理路径

§6.2 的故障段先说注入1000次随机链路故障，再报拓扑修复平均83.8 ms，随后把大部分时间定位到远端报告和指令往返。最后一句转向下一节：数据面可在本地容忍部分故障，使数据更快继续走。这句没有重复“我们的恢复更快”，它明确指出了下一实验要绕开的等待来源。

§6.3 的故障段随后按条件推进：故障后拓扑仍连通时，本地选择其他可用链路；拓扑断开时，先缓存并等待控制面。两组结果因此有各自的输入条件。把83.8 ms和13.6–44.3 ms写成所有故障中“同一算法优化前后”的对照，会丢掉这一区别。

原文图17d实际位于 p.11，把上报、MPC计算、下发和总修复时间画成不同 CDF；这让读者能从时间分布辨认控制计算与传播的相对量级。按两项报告均值相减，仅剩约0.3 ms，占总均值约0.36%。即使把这些剩余平均开销完全省掉，仍有约83.5 ms往返。因此这组数据支持将可本地完成的动作前移，而不支持只加快优化器就能大幅缩短此处总恢复时间。该核算只处理报告均值，不推导尾时延。

图19d在同页保留故障前后分组处理记录与故障／无故障比较，用于观察局部动作；图19b则另画端到端 RTT。作者选择不同图来表示不同边界，这个信息组织值得保留。读者仍需知道本地检测时刻如何确定，才能进一步写从物理故障发生到业务恢复的完整预算。

### 重点二：恢复连接以后，还要清空多少积压

选择这个重点，是因为“可以缓存直到修好”容易被读成“数据业务不受影响”。§4.3 给的是有条件的转发过程；§7 还将确定性网络能力列为未来增强方向。本文没有把缓存容量、到达负载、恢复后的服务率及每包截止时间合成一个上界。这个空白可转为清楚的新实验问题，而无需否定已有局部恢复结果。

助手原创算例：假设某业务持续产生3000条记录／秒，每条32字节，故障期间完全无法发送，起始无积压。借用83.8 ms这个**论文报告的平均修复时间**作为一次假设停顿，产生约 $\lceil3000\times0.0838\rceil=252$ 条积压，光载荷就需8064字节缓存。这里没有计报文头、重复副本或其他流量。

恢复后若服务率为6000条／秒，而新数据仍以3000条／秒到来，净清空速率仅3000条／秒，按恒定速率近似，排空这批积压还需 $252/(6000-3000)=84$ ms。网络在83.8 ms时恢复连通，队列约再过84 ms才恢复到空。若服务率恰好等于到达率，持续到来的数据会使原有积压无法净减少。

对于100 ms批次期限，故障出现在第70 ms时只剩30 ms；即便某次修复恰好等于83.8 ms，最早修好也已到第153.8 ms，还没计发送。这是说明期限与恢复时刻关系的自拟情形，不是把卫星故障时延预测给 UWB，也不把平均修复时间作为最坏界。

### 原创英文改稿

以下为助手自拟段落，不是原文或用户稿件。

**差段：**

> Our network recovers from every failure within 44.3 ms. If no path is available, buffering guarantees that all packets still meet their deadlines. The controller repairs the topology in 83.8 ms, so the recovery cost is negligible.

**诊断：** 第一句把连通条件下的局部结果扩展到全部故障；第二句从存下数据跳到按时送达；第三句既省略平均值身份，也没有相对于业务期限判断成本。

**改段：**

> We distinguish failures that leave an alternative forwarding path from failures that disconnect the required region. In the first case, a local forwarding decision can resume transmission without waiting for the remote controller. In the second, packets remain queued while the controller restores connectivity. We report topology repair time separately from the time to deliver the queued traffic, because arrivals during the outage can extend the latter even after a path becomes available. The deadline experiment therefore records fault detection, the first successful post-fault transmission, and completion of the affected batch under the same offered load.

### 重点一：三个参照让“误差来自哪里”成为可检验的问题

§5.1、p. 9 先列出标准明文 DSP、相同 mmFHE 处理核的明文执行，以及仅分类阶段加密的 RPRS 三种参照，再定义各任务的比较单位。这个顺序是值得复用的正向写法：先让读者知道要固定哪个因素，再报告数字。

§5.2 的推进进一步细化为：①用表 3 比较同一处理流程在加密与明文下的输出；②说明每一行是在前面核已经执行后的累计结果，采自每条流程三段测试记录；③再把数学等价的 DFT/FIR 等操作与软选择、相位近似分开；④使用标准 DSP 参照评估后者的功能替换代价。§5.3 接着把输出差异落到手势标签上。作者据此把加密数值扰动与适配固定电路的算法代价分别讨论，而非让一个“明文基线”承担所有比较。

**可复算的实验链。** 表 5 六折明文正确数为 $72+88+82+92+86+88=508$，加密正确数为 507；分别除以 600，得到约 84.67% 与 84.50%。只有一条预测不同，对应 $599/600\approx99.83\%$ 一致率。显示的约 0.2 个百分点变化与一条记录的差异一致。这说明加密执行在这一流程上的额外标签变化很少；它没有证明这条流程已经达到其他特征和网络的精度。§5.5、pp. 11–12 的 95.0% 参照采用不同处理流程，不能把约 10.5 个百分点差距全部归给加密算术。

另需明确评估单位：§5.1 写手势训练/划分使用一个主体在六个环境的名义记录，每折抽取 100 条测试；这里不扩写成已验证跨主体泛化。表 3 的“低于 $10^{-5}$”针对 MSE，K2 同表的最大绝对误差可为 $6.9\times10^{-3}$，不能把二者互换。表 4 的波形误差与“相同流程”的比较对象仍有需要澄清的表述，本笔记不据此推导临床精度或独立的波形保真结论。

### 重点二：软峰值选择保留固定计算流程，却改变输出的意义

§3.3.3、p. 6 的 K2 先给能量权重 $w_r=E_r^\gamma$，再给加权位置 $\hat r=\sum_r rw_r/\sum_r w_r$，最后说明增大指数可让权重集中但会消耗更多乘法深度。它把一个实现限制转成可调的计算取舍，读者能看到参数的实际作用。

**原创最小例。** 只考虑第 0 与第 4 个距离单元，能量分别为 4 与 3。硬最大值选择第 0 个单元；取 $\gamma=2$ 时，软输出是

$$\hat r=\frac{0\times4^2+4\times3^2}{4^2+3^2}=1.44.$$

取 $\gamma=4$，输出约 0.961。它逐渐靠近最大峰，但仍不是该峰的离散编号。若两峰能量相等，任何指数都会给中间位置 2。软选择可以在一个主导峰明显的场景中充当近似，却不能自动承担分离多目标的任务；原文 §7、p. 13 也明确现有核会将场景压缩为单一主导主体。本例没有把两个能量值冒充论文数据。

这条机制也解释为什么精度评估要保留三种参照：即使加密和明文的软输出都精确等于 1.44，加密误差为零，软选择与硬选择仍有功能差异。若下游只需要平滑的能量位置趋势，这个输出可能有用；若动作必须选中某个真实目标编号，就需要明确定义恢复步骤或改变输出接口。

**待改稿：** Encryption does not reduce sensing accuracy. Our accuracy is almost identical to plaintext, proving that the approximation preserves all radar information. The error is below ten to the minus five for every output.

**完整改稿：** We isolate encryption error by executing the same FHE-compatible pipeline on plaintext and ciphertext inputs. Across six environment-held-out folds with 100 test recordings per fold, the two executions agree on 599 of 600 gesture predictions; their accuracies are approximately 84.7% and 84.5%. This comparison measures the additional effect of encrypted arithmetic within the chosen pipeline. We evaluate the functional cost of replacing standard DSP operations separately, because agreement with the plaintext implementation does not establish equivalence to hard selection or other feature extractors.

**修改理由与条件：** 第一行先固定算法；中间用记录数核对百分比；后两句交代另一个参照负责哪项判断。适用于量化、压缩、近似计算或加密执行，只要系统既换算法又换数值表示，就应把两种改变分开。可复用搭配 **execution of the identical pipeline** 来自表 3/§5.2，使用时应同时确认参数、输入和后处理相同。

### 原创英文训练二：把接口选择写到可执行的输出上

**待改稿：** Soft attention securely identifies the strongest node. We round its output to obtain the node ID, so the gateway can always select the correct device without receiving additional information.

**完整改稿：** The soft statistic is a weighted index, so it should not be interpreted as an exact device identifier. For scores of 4 and 3 at indices 0 and 4, a squared-energy weighting returns 1.44, although index 0 has the larger score. If the downstream action requires selecting an existing device, the interface must preserve that discrete decision. **修改理由与条件：** 改稿先说输出是什么，再用最小例指出动作需求，最后给出可执行的替代接口。这个网关接口是助手推想；论文手势流程确实让客户端在解密 logits 后做 argmax（§3.3.4–3.3.5），但没有验证上述节点选择任务。

### 重点一：一次生成的对象可以是“工具”，而不只是下一步答案

### 原创可执行例：99%的平均分仍可能错过最后一条记录

这是助手构造的模型和数据，没有运行LLM生成或完整GIF-MCTS。状态k表示还差多少条记录。send使k减1，消耗0.01；发送最后一条时，完成奖励抵消成本后为0.99且done为真。wait不改变状态，奖励0。

构造100个一步记录，其中99个为k=2时发送，1个为k=1时发送。故障模型总能算对下一状态，却漏掉完成奖励和done。按原文式2的三项均匀匹配评分，得到(100+99+99)/300=99.333%。但在k=1时做一步规划，故障模型比较wait的0与send的−0.01，会选择等待；正确模型看到send的0.99，会立即发送。

这不是说模型必须在所有无关细节上100%正确，而是要检查会改变决策的事件。对限时交付，最后一条收齐、重试次数耗尽、截止时间到达都应分别计分。有限样本上的总均值不能替这些事件给出保证。

同时核对了作者当前实现的变化：commit `e17e787b41137793bcef9f860bdfe9e6fc07b768` 的`simulator_cwm.py`默认按奖励类别加权，终止事件只比较奖励和done，连续状态还用容差。独立抽取并执行原作者验证函数，在同一自拟数据上，关闭类别加权得到0.99，打开后得到0.50；完整正确模型为1.0。论文公式、当前实现未加权值和当前默认值是三种不同定义，本记录分别保存。这个实现说明稀少关键事件可以通过评价权重暴露，不把原文的平均分概念直接等同于当前代码。

### 四板研究问题与工具落地路线

已有10000轮每轮300条记录100ms内完成，可以作为正常事件回放样本。新增问题是：规定一个叶节点重启、延迟ACK或批次编号切换时，状态机是否仍能准确区分旧记录、重复记录与当前缺失记录？先依据现有实现建立参考step函数，生成器产物必须匹配它，再用新的事件排列测试。研究的是状态定义与异常顺序下的处理，不能通过重新验证正常基线制造新增贡献。
