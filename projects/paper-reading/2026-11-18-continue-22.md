## Partial-Causal-Discovery

Muhammad Qasim Elahi、Mahsa Ghasemi、Murat Kocaoglu，*Partial Structure Discovery is Sufficient for No-regret Learning in Causal Bandits*，NeurIPS 2024，DOI [10.52202/079017-3462](https://doi.org/10.52202/079017-3462)。[正式出版页](https://proceedings.neurips.cc/paper_files/paper/2024/hash/c50e3c72bf45a361afc7c16d26c21a1a-Abstract-Conference.html)，[正式全文](https://proceedings.neurips.cc/paper_files/paper/2024/file/c50e3c72bf45a361afc7c16d26c21a1a-Paper-Conference.pdf)，[作者代码](https://github.com/CausalML-Lab/CausalBandits_with_UnknownGraph)。本篇首次收录，重点是把模型学习目标限制到实际决策需要，以及理论之后的实验怎样展示节省来自哪里。

### 六项研究卡

问题：系统因果关系未知且存在共同隐藏原因时，怎样减少寻找高奖励干预所需的试验？缺口：把每种参数组合都当作独立动作会形成庞大动作空间；先完整恢复所有因果关系又会消耗大量样本（§1–2）。观察：不同因果图可能给出相同的可能最优干预集合，因此有些关系对当前决策候选没有影响（§3，图1）。方法：先找到奖励的祖先及相关有向关系，再辨认会改变可能最优干预集合的隐藏共同原因，最后在该候选集合上运行UCB（§4–5）。证据：§6在50个随机图、不同有向与隐藏关系密度下比较学习样本量，再分别报告候选空间与累计遗憾（图2–4，pp.9–10）。范围：理论针对离散变量、二值奖励及可干预模型，要求相应忠实性、可检测差距和概率下界；最坏情况下候选动作数仍可能指数增长。

### 重点一：把“模型够不够好”改成“是否保留正确的候选动作”

这篇的核心 insight 是：**先决定模型将用于哪个选择，再学习能保留该选择的结构。**例如调一个系统的控制参数，最终任务是找到好的设置，完整解释所有内部关系可以留给另一项研究。论文把这个想法写成明确对象：可能最优的最小干预集合，简称POMIS。集合中的某项在某个与结构相容的系统里可能最好，因此在只知道结构时应保留。

§3先说明为何不能只关注奖励的直接父节点。隐藏因素同时作用于中间量和奖励时，固定中间量可能切断原有的有用响应，上游动作仍可能更好。随后作者引出POMIS，再问完整图中哪些关系必须知道。图1保持相同节点与有向结构，分别去掉一条双向边。两种删除会改变候选集合，另一种删除保留相同集合。这个顺序先让读者看见决策差异，再给必要充分条件。

实际查看p.4图1后，四个小图采用相同节点位置，虚线双向边表示隐藏共同原因；正文紧接着列每个图的候选集合。这是适合借鉴的图文关系：图负责显示只改了哪一项，集合负责显示该变化是否影响后续选择。它没有要求读者仅凭图形复杂度判断哪条边重要。

**原创随机系统算例。** 令可控上游量为 $A$，中间量为 $B$；隐藏因素 $U\sim\mathrm{Bernoulli}(0.3)$，独立扰动 $E\sim\mathrm{Bernoulli}(0.1)$。自然机制为 $B=A\oplus U\oplus E$。当 $B=U$ 时，二值奖励为1的概率为0.9，否则为0.2。没有干预时，$A$等概率取0或1。

这里 $A\to B\to Y$，且隐藏因素同时影响 $B$ 与奖励 $Y$。精确枚举所有隐藏状态后，得到：

| 干预 | 期望奖励 |
| --- | ---: |
| 不干预 | 0.55 |
| 固定 $A=0$，让 $B$ 按机制响应 | 0.83 |
| 固定 $A=1$ | 0.27 |
| 固定 $B=0$ | 0.69 |
| 固定 $B=1$ | 0.41 |

固定 $A=0$ 时，$B$有90%的概率与隐藏状态匹配，奖励为 $0.9\times0.9+0.1\times0.2=0.83$。直接固定 $B=0$ 后，匹配概率成为0.7，奖励为0.69。再同时固定A和B，奖励仍由固定B决定，枚举的四种双变量设置也未优于0.83。这个原创例说明“离结果更近的参数”未必是最佳控制入口；它没有被宣称满足原论文所有图发现假设，也未用于复现其遗憾定理。

另按图1正文给出的候选集合复算动作数：三个二值变量，每项可不干预、设0或设1，总共 $3^3=27$ 个动作，其中含一个完全不干预动作。该示例的候选集合为不干预、三个单变量集合及一个双变量集合，对应 $1+2+2+2+4=11$ 个动作。学习保留这个候选集合的结构，可以把后续要比较的动作从27缩到11。这是对论文所列集合的计数，不表示所有三变量系统都有相同缩减。

### 重点二：从最坏界过渡到机制实验

§5先把累计遗憾分成发现结构的前期代价和候选集合上持续试验的代价。到§6开头，作者明确指出最坏界可能需要检查全部相关隐藏关系，而实际算法只检查足以保留候选集合的一部分；节省量随图结构变化。实验因此从“在哪些结构下节省多少”开始，而非直接重复定理结论。

作者交代随机图生成、有向边密度、隐藏共同原因密度、50个图及二值变量，然后用图2比较三个层次：仅学习有向结构、学习决策所需结构、学习包含全部相关隐藏关系的结构。实际查看p.9，九幅子图按两种密度排列，横轴都为节点数量，但纵轴量级并非全部相同。读图时应比较同一子图内的关系，不能只凭九幅图上曲线的视觉高度判断绝对成本。

图3转向完整动作空间与结构发现成本，图4才给最终UCB阶段的累计遗憾。这样“少学了关系—少保留了动作—减少了决策损失”分别对应可检查的证据。p.10还说明累计遗憾经过下采样，探索阶段的细分变化在大尺度图中被压缩；采样后的线段形状不应直接当作每一轮的行为。

这套写法可用于组网调参：先报告排除多少候选、为此多做多少试验，再报告总调参代价与最终系统性能。只展示候选数量下降，会遗漏前期辨认关系的成本；只展示最终最佳参数，又不能解释结构学习是否带来帮助。

### 原创英文练习

以下差段和改段均为助手原创，面向计划中的组网调参实验。

**差段：** “We learn the complete causal model and remove irrelevant parameters. The smaller search space guarantees faster tuning. Our method identifies the best settings with few experiments, regardless of hidden system states.”

**完整改段：** “Our objective is to preserve the candidate interventions needed for parameter selection. We therefore learn the relationships that can change this candidate set and leave the remaining structure unspecified. We first measure the experiments spent on structure discovery and the number of interventions retained afterward. We then run the same selection algorithm on the reduced and original action sets, counting discovery trials in the total tuning cost. To test the role of hidden operating states, we evaluate both procedures under controlled changes in receiver workload and report the final performance together with the number of physical trials.”

改段先将模型目标落在候选保留，再把节省和前期代价放到同一总成本里。最后用真实环境变化检验适用范围。**preserve the candidate interventions** 适合有明确定义候选集合的方法；**counting discovery trials in the total tuning cost** 适合先学习再优化的两阶段系统，要求两类试验都确实记账。

### 可接到当前组网工作的研究问题

四板系统已有每轮300条、100 ms内收齐的结果。后续降低能耗时，可问：**在发射功率、接收保持时间、处理频率和补发配置的组合中，能否用少量受控试验先缩小候选集合，再寻找满足既有时限的低能耗设置？**这里只把真正可设置的量列为动作；接收机内部状态或环境干扰作为观测或隐藏因素，不能任意当作可硬干预变量。

最小实验先在可解释的离散事件模拟器中构造一个小参数空间，保留全枚举最优值；比较全空间搜索、只看直接影响量的缩减、针对候选集合的结构学习。总成本包含发现阶段和选择阶段，指标包括最优候选保留率、物理试验次数以及达到目标后的能耗。随后在有权限的实测环境中，用有限的预先允许配置验证。论文的二值奖励可以启发“同时满足时限与能耗门槛”的简化任务，但改变奖励定义会改变相关结构与候选，需明确重新评价的对象。

## BSense

Chengzhen Meng、Chenming He、Yidong Jiang、Xiaoran Fan、Dequan Wang、Lingyu Wang、Jianmin Ji、Yanyong Zhang，*Needle in a Haystack: Tracking UAVs from Massive Noise in Real-World 5G-A Base Station Data*，MobiSys 2026，pp. 14–27，[DOI](https://doi.org/10.1145/3745756.3809186)。采用[作者公开的 14 页正文](https://hechenming.github.io/assets/pdf/BSense.pdf)，会场与作者信息由 DOI 题录及[作者发表列表](https://hechenming.github.io/publications/)交叉核验。本次为新读，页码均按该 PDF 页序。

### 六句研究卡

**问题：**商用 5G-A 基站可输出大范围点云，但在真实城市场景中，无人机点被大量持续出现的噪声点包围（§1，pp. 1–2）。**缺口：**单点 SNR、Doppler 等特征分布重叠，而且噪声也能形成长期轨迹，因而仅用强度阈值或轨迹持续性不足以区分目标（Fig. 1–3）。**观察：**背景回波与所在区域相关，局部信号特征分布比全场景原始特征更有区分信息（§3.2，p. 4）。**方法：**系统按局部噪声指纹、对象运动一致性、轨迹分类三层逐步筛选，无法通过局部高斯检验的区域交给后两层处理（§3.2–3.4）。**证据：**首层将平均噪声点数由每帧 168.05 降到 64.15，去掉 61.8% 噪声点并误删 1.7% 无人机点；完整系统在该数据集的 F1 为 95.56%、平均定位误差 4.9 m（§4.3、§4.5，pp. 10–11）。**范围：**输入是基站已生成的点云，作者未修改底层信号处理；原始数据中持续没有目标点时，输出仍会出现轨迹中断（§2、§5，pp. 3、12）。

### 重点一：从单点重叠走向带背景的判断

§3.2 的开头（p. 4）先限定本层处理的对象：来自建筑、地形和树木的持续背景。接着指出这些点也可能有非零速度和较高强度，解释单点阈值为何不够。下一段才改变观察单位，从单个点转到局部区域的统计分布；随后给出物理依据、定义噪声指纹，并预告“检验分布—估计参数—计算偏离程度”的流程。这样写使方法的每一步都能追溯到前一个问题。

§3.2.1 随后给出作者的理论动机与经验检验。作者用多个散射源叠加和局部环境相对一致解释高斯近似，再对 10 分钟无无人机数据、边长 40 m 的空间块应用 Henze–Zirkler 检验，报告超过 75% 的块通过。其余块不强行套用高斯过滤，而留给对象与轨迹阶段。这里最值得迁移的是明确写出模型不适用时数据流向哪里。散射叠加提供动机，多个非线性信号质量指标是否联合高斯仍靠实际检验支持；“通过检验”也不等于对所有未来数据证明了该分布。

§3.2.2–3.2.3 给出每块独立标准化、协方差估计及 Mahalanobis 距离。该距离小表示更像当地噪声，会被删除；这与把“大距离当作噪声”的普通离群点清理方向不同。实际查看 p. 4 的 Fig. 5，作者按空间网格、局部分布、椭圆等距轮廓排列图形，将“在哪里建模”和“怎样比较相似度”接在一起；这些是作者的解释设计，双栏版面来自出版模板。示意椭圆没有给出真实点的误删概率，概率效果由后面的实验承担。

**原创核算一：背景条件改变结论。** 假设两个区域的单维背景分别为 $N(-3,1)$ 和 $N(3,1)$，权重相同。忽略区域后，用单高斯拟合得到均值 0、方差 $1+3^2=10$。对新点 $x=0$，若它属于第二个区域，当地标准化距离为 3；全局模型的距离却为 0。采用“距离小于 2 则视为背景”的自拟阈值，当地模型保留该点，全局模型将它删除。这个例子说明混合两个背景可能使原本不典型的中间值看上去最典型；它不是原论文数据，也未使用论文的五维特征。

**原创核算二：特征相关性改变结论。** 令标准化背景的均值为零、协方差为

$$
\Sigma=\begin{bmatrix}1&0.9\\0.9&1\end{bmatrix}.
$$

两个点 $(1,1)$、$(1,-1)$ 的欧氏距离平方同为 2，但 Mahalanobis 距离平方分别为 $2/(1+0.9)\approx1.053$ 和 $2/(1-0.9)=20$。在自拟距离门限 2 下，第一点像背景而被过滤，第二点被保留。原因是背景中两个特征通常同向变化；一增一减虽然幅值相同，却更违背这个关系。矩阵和阈值均为助手构造，仅用于解释式 (10)。

### 重点二：让参数图同时呈现删掉什么和保留什么

§4.3 第一段（p. 10）的顺序是：说明历史帧数影响估计与存储，引出 Fig. 16，观察噪声过滤率的增长及约 700 帧后的收益减小，再核对无人机误删率，最后确定运行参数。这种写法为“为什么取 700”提供完整证据链。700 帧按 0.64 s 帧间隔计算为 448 s，即约 7.47 分钟，与正文约 7.5 分钟一致。

实际 Fig. 16 将无人机误删率和噪声正确过滤率分为两幅图，各自标明对象与方向，在选定参数处用虚线和数字标出 1.7% 与 61.8%。这能避免把“删得更多”直接当作改进。紧接着的 Fig. 17 研究更新间隔，Fig. 18 再按飞行形状检查同一配置；三个问题依次是“需要多少样本”“多久更新”“换轨迹是否保留目标”。实现与实验段采用 2 天更新间隔；参数应按这里的具体设置理解。

一个容易混写的数字是 §3.2.3 的第 80 百分位门限。它规定历史噪声距离的经验分位数，并不承诺新数据一定去掉 80% 噪声；本数据上的实际去噪率为 61.8%，由 $(168.05-64.15)/168.05\approx61.83\%$ 可复核其舍入。同样，后续每帧 0.04 个虚假对象与首层每帧 168.05 个噪声点属于不同表示层，引用时应保留“点”和“对象”的单位。

附录 A（p. 14、Fig. 26）把空间块变大导致召回下降的现象，与不同反射环境被混在一起的解释相连。图给出端到端性能随块大小的变化，混合反射性质是作者的归因；若要单独证明该机理，还需比较块内分布变化。这恰好与上面的双背景最小例相互补充。

### 原创英文改稿与引图练习

以下段落和图文均由助手自拟，非论文原句或用户稿。

**差段：** “Noise follows a Gaussian distribution, so any point far from the mean must be a UAV. Our 80th-percentile threshold removes 80% of noise everywhere. A larger background region gives more samples and should improve the detector.”

**完整改段：** “We model background statistics within local spatial regions because reflections from different surroundings need not share the same distribution. A point is evaluated against the model of its own region, and low-distance points are removed as background-like observations. Regions that fail the Gaussianity check bypass this filter and are handled by the later stages. We choose the distance threshold from historical noise samples and evaluate its effect separately on new noise points and UAV points. This separates the threshold's definition from the observed filtering rates and makes the cost of discarding useful target evidence explicit.”

改稿把分布的适用单位写进首句，清楚交代相似度方向、失败分支及评估对象；删去“大距离必然是真目标”的跳跃。适用于按环境或设备状态建立背景模型的系统；后续模块仍要处理被保留的其他异常，不能仅凭背景偏离就给出确定目标类别。

**自拟引图句：** “Figure X compares the same observation against a local background model and a pooled model.”

**自拟完整图注：** “**Background-dependent filtering in a one-dimensional example.** The two regions have background means of −3 and 3 with unit variance. Pooling them produces a single Gaussian approximation centered at zero. The observation at zero is atypical for either local background but lies at the center of the pooled approximation.”

**解释句：** “The example shows why adding heterogeneous samples can change the meaning of a small distance, rather than merely improve parameter estimation.”

这是原创机制说明图的文字设计，未生成图像，不将其当作论文实验。可复用表达为 §4.3 的 **marginal gains diminish**（p. 10），用于描述继续增加样本后收益变小；使用时应有横轴继续增长、收益增量下降的结果支持。

### 对电芯网络的新增条件与决定

已有桌面 10,000 轮、每轮 300 条记录全部在 100 ms 内收齐，其中 5,131 轮重传一次，4,869 轮重传 2–4 次。新增条件可设为节点进入多个发射功率档与温度状态后，CIR 摘要和接收功率的正常背景也随之改变。此时需要决定的是何时花一条额外探测报文更新链路配置，而不是重新证明现有桌面数据能否收齐。

## LoRaTrimmer

论文：Jialuo Du, Yunhao Liu, Yidong Ren, Li Liu, Zhichao Cao，*LoRaTrimmer: Optimal Energy Condensation with Chirp Trimming for LoRa Weak Signal Decoding*，MobiCom 2024，1104–1118 页，DOI：[10.1145/3636534.3690681](https://doi.org/10.1145/3636534.3690681)。[作者全文](https://cse.msu.edu/~caozc/papers/mobicom24-du.pdf)；[作者实现，本次固定版本](https://github.com/LoRaTrimmer/LoRaTrimmer/tree/4b480e7e28472f9e1ccdbf232533f5a441c4d361)。以下页码按 15 页 PDF 顺序计。

此前记录已学习按候选频率切分波形、避免随机相位抵消。本次转向两个连接系统落地的问题：复杂度如何对应处理预算，以及负载解码增益为何没有等幅变成前导码检测增益。

### 六句研究卡

1. **问题。** LoRa 弱信号解码希望更充分地利用接收能量，同时网关还须及时处理不断到来的符号（§1，第 3 页）。
2. **缺口。** 分别为所有符号候选计算两段相关量，直接实现需要大量重复计算；仅证明符号判决更准，也不能保证前导码更容易被发现。
3. **观察。** 候选相关和可以按等间隔子序列分组，多个候选的计算存在前缀和共享；另一方面，前导码的基础上扫频没有负载随机码所带来的相位跳变（§3.3，第 8 页；§5.11，第 12–13 页）。
4. **方法。** 作者用分治将计算量从 $O(n^2)$ 降到 $O(n^{3/2})$、存储降到 $O(n)$，并将相应匹配操作扩展到前导码滑窗检测，其中 $n$ 是每符号采样点数（§3.3–4）。
5. **证据。** §5.12 表 2 报告 16 符号的包在 SF7–12 时处理耗时为 0.51–3.17 ms；§5.11 图 18–19 的 90% 检测门槛相对 HFFT 改善 0.45–0.55 dB，明显小于负载符号解码实验中的改善（第 12–13 页）。
6. **范围。** 时延是在 Ryzen 9 5950X 与 RTX 2080 Ti 所在平台测得，不能直接写成微控制器时延；检测、符号准确率和整包交付率也有不同的分母。原文 TinySDR 部署属于可行性讨论，本次未找到对应的实测部署结果。

### 重点一：复杂度的自变量必须接到到达速率

§3.3 的推进顺序适合写优化算法：先把解码表达成矩阵运算，明确直接实现为何贵；再定义分组参数 $q=2^{\lfloor\log_2 n/2\rfloor}$；随后用单位根的周期关系说明相关项怎样共享前缀和；最后算出总时间和可原地累加的存储量。作者紧接着解释 SF、带宽、采样率怎样改变 $n$，把渐近符号接回无线参数。

这里可以再做一个区分：每符号计算量和每秒必须完成的计算量。**助手自拟推导**：保持带宽与采样率，SF 减一会使 $n$ 减半，每符号主导计算量变为原来的 $2^{-3/2}$，同时连续符号到达速率翻倍，故每秒总量约变为 $2\times2^{-3/2}=1/\sqrt2$。若固定 SF 并将带宽、满足采样条件的采样率一起翻倍，每符号样本数可不变，但符号到达速率翻倍，每秒预算仍会变紧。这个推导只跟踪主导项，不包含线程、缓存和固定开销。

§5.12 接过前面的复杂度结论：先固定 16 个符号与平台，挂表 2；再将处理时长与信号持续时间比较；然后分别解释为何快于 NeLoRa/LoRaPhy、仍慢于只做 dechirp/FFT 的 HFFT/MFFT。它把成本放在一个能解释的参照物旁边。

以文中 125 kHz 带宽手算，$T_{\mathrm{sym}}=2^{SF}/B$。SF7 的 16 个符号占 16.384 ms，表 2 处理 0.51 ms，占约 3.11%；SF12 占 524.288 ms，处理 3.17 ms，占约 0.60%。这是对单个负载块的处理预算检查，尚未计入连续前导码扫描、多个信道争用计算资源与数据搬运，不能直接据比例推出可并发节点数。

作者公开脚本为这条判断提供了一个可检查的实现边界。固定版本的 `gen_constants` 为每个候选建立两张稠密 `complex64` 矩阵，`decode_ours` 使用矩阵乘法；该脚本没有呈现 §3.3 的低存储分治流程。在默认 1 MHz/125 kHz 下，两矩阵合计 SF7 为 2 MiB，若扩展到 SF12 则为 2 GiB。已按数组形状和每元素 8 字节独立计算。这不影响解码思想本身，但复用这个公开演示时，不能把论文的 $O(n)$ 存储性质直接归给现成脚本。

### 重点二：较小的阶段收益也能支持方法解释

§5.11 没有把检测结果合并进负载解码曲线。段首先说明要检查前导码检测，随后固定 SF7，改变前导码的 8、16、32、64 个上扫频数量，并为各方法使用相同检测规则：寻找固定数量的周期峰，峰位偏差不超过一个 bin。然后先给图 18 的检测率曲线，再用图 19 摘取 90% 门槛，最后解释为什么增益较小：基础上扫频不含负载随机符号的相位跳变，因此 HFFT 已经接近 LoRaTrimmer。

实际查看第 12 页可见，图 18 用一条水平虚线标 90%，图 19 的横轴改为前导码数量，回答增加训练长度怎样移动检测门槛。虚线和坐标变化是作者组织证据的选择；会议双栏不是该实验设计。这里的积极写法是用较小收益检验机制：方法针对的问题在某阶段减弱，优势也相应减小。若只摘最好的 dB 数字，这层解释就丢了。

**助手自拟代价算例。** SF7、125 kHz 下，一个上扫频为 1.024 ms；从 8 个增加到 64 个，仅新增的 56 个上扫频就占 $56\times1.024=57.344$ ms。这个时间未包含其余帧字段。于是“加长前导码改善检测”在 100 ms 周期中会占掉相当一部分预算，必须同时报告交付机会减少多少。

另一个解释整包指标的理想算例：设检测成功概率 0.9，检测后 16 个符号各自正确率为 0.99，且暂按独立、无编码纠错，则整包全对概率为 $0.9\times0.99^{16}\approx0.7663$。原文没有给出这个独立错误模型，它只提醒报告“90% 符号准确率”时不能直接改写为“90% 整包可靠”。

### 完整原创英文改稿

以下由助手自拟，非论文原句或用户稿。

**差段。**

> Our decoder has low complexity and runs in real time. It improves sensitivity by several decibels, so the receiver can reliably collect packets at a longer distance. Increasing the preamble length further improves performance with little overhead.

诊断：复杂度缺少自变量与工作负载；符号解码跨越到了整包可靠；“little overhead”没有对应周期预算。

**改段。**

> We evaluate computational feasibility and packet acquisition separately. For a fixed block of 16 payload symbols, we measure decoding time across spreading factors and compare it with the duration of that block on the air. We then evaluate preamble detection using the same peak-consistency rule for all receivers. The smaller detection gain is consistent with the signal structure: base upchirps do not exhibit the phase discontinuities targeted by the payload decoder. Finally, we report the airtime added by longer preambles so that the detection benefit can be assessed within a fixed collection period.

改段用两个实验对象带出两种证据，再通过信号机制解释收益差异，最后把训练长度接到周期约束。该结构适用于分阶段接收机；若硬件联合检测与解码、不能分离中间事件，应改为可观察的联合指标，不能凭空构造阶段成功率。

英文搭配 **“with the same position and phase”** 位于 §4、第 9 页，说明连续前导码峰的一致性条件。借用这类句式时，应明确哪个测量量在多次观察中保持一致。

## GaLore

Jiawei Zhao, Zhenyu Zhang, Beidi Chen, Zhangyang Wang, Anima Anandkumar, Yuandong Tian. **GaLore: Memory-Efficient LLM Training by Gradient Low-Rank Projection**, ICML 2024，PMLR 235:61121–61143。正式标识 **pmlr-v235-zhao24s**，会方页面未列 DOI。[正式题录](https://proceedings.mlr.press/v235/zhao24s.html)；[会方全文](https://raw.githubusercontent.com/mlresearch/v235/main/assets/zhao24s/zhao24s.pdf)；[作者实现](https://github.com/jiaweizzhao/GaLore)。以下使用 PDF 页码。

### 六项研究卡片

- **问题。** 全参数训练除了保存权重，还需要梯度及优化器状态；Adam 的两组逐元素统计可能构成显著存储负担（§1、§3.1，pp. 1、3）。
- **缺口。** 始终把可学习的权重变化限制在一个低秩表示中，可能约束模型的搜索方向；省内存不必只能从可训练参数数量入手（§3.2、§4，pp. 3–5）。
- **观察。** 一段训练过程中，梯度可能主要集中于少数方向；这个局部结构可以用于压缩梯度统计，但主方向会随训练变化（§3.2、§4.1，pp. 3–5）。
- **方法。** 投影当前梯度，在小矩阵中更新优化器状态，再将更新投影回原空间写入完整权重；定期从当前梯度重新计算投影基（§3.3–§4.2、Algorithm 2，pp. 4–6）。
- **证据。** Table 2 的 LLaMA 1B、C4、13.1B 训练 tokens、秩 512 设置下，GaLore 验证困惑度为 15.64，完整更新为 15.56；基于 BF16 的参数加优化器状态存储估算为 4.38 G 与 7.80 G，约减少 43.8%。这是指定组件的估算，不是进程总显存（pp. 7–8）。
- **边界。** 低秩梯度的理论结果有梯度形式和训练条件；更换投影的频率、梯度噪声与谱分布会影响效果，原文没有证明任意无线模型都能保持完整优化器的轨迹（§3.2–§4.1、§6，pp. 3–5、9）。

### 工具动作：压缩的是哪一份状态

设一层权重 $W\in\mathbb R^{m\times n}$，$m\le n$。实用版本保留完整的 $W$，用 $P\in\mathbb R^{m\times r}$ 左投影梯度，得到 $R=P^\top G$；Adam 的一阶和二阶统计都在 $r\times n$ 空间累计。更新完成后乘回 $P$，再写进原权重。输入是当前梯度、上次投影基和低维优化器状态，输出是新的完整权重及低维状态（§4.2，p. 6）。

如果只保存一个固定 $P$，新梯度即使转向，也可能被投影丢掉。§4.1 因此让多个低秩子空间依次参与训练：每隔 $T$ 步用当前梯度的 SVD 重选基，之前写入权重的变化继续保留。每次变化可以低秩，累计变化却不必保持同一个低秩空间。这里的“全参数”说明哪些权重能被更新，不表示低秩 Adam 与完整 Adam 在每一步数值相同。

### 学习重点：用一个失败情形推动设计，再把内存与学习时间写成可选择的取舍

本篇选**设计段落的因果衔接**和**二维实验的解释方式**。它们适合此文，因为读者容易把“梯度低秩”直接理解成“一个固定小空间已经够用”，也容易把“内存更少”理解成“训练更快”。

§3.3 在给出投影更新后，下一页讨论固定投影下的进展。§4 开场立即留下一个尚未解决的问题：复杂训练的主要方向会变化，固定子空间无法覆盖整个过程。然后 §4.1 给出式 14，把完整变化写成多个阶段更新之和；Fig. 2 画出先沿蓝色平面、再沿橙色平面推进的轨迹。图中的用途是解释空间更换，不能把示意路径当作作者实际记录的梯度轨迹（p. 5）。

下一段才引入 $T$，按两端讨论其影响。更换过快，需要多做 SVD，也会影响跨步累计统计；更换过慢，则可能一直更新已不重要的方向。作者没有把 $T$ 只列成实现超参数，而是让它承接前面的失效机制。随后 §6 用 Fig. 5 左图改变 $T$、用不同曲线区分秩，检查这种权衡；这使实验回答的是“怎样更换才合适”，而不只是“系统是否胜过基线”（pp. 5、9）。

### 原创最小例：每步秩一，累计变化仍可为秩二

设一个两通道校准层的目标矩阵为 $W^*=\operatorname{diag}(2,1)$，初值为零，损失 $L(W)=\tfrac12\|W^*-W\|_F^2$。这是说明更新空间的原创线性问题，矩阵元素无物理单位；采用步长 1、无动量 SGD 和尺度系数 1，不代表论文默认 Adam 实验。

初始负梯度为 $G_0=\operatorname{diag}(2,1)$。秩一的最大奇异方向为 $P_0=e_1$，投影更新 $P_0P_0^\top G_0=\operatorname{diag}(2,0)$，所以 $W_1=\operatorname{diag}(2,0)$，损失从 2.5 降到 0.5。

第二步负梯度为 $G_1=\operatorname{diag}(0,1)$。若仍用 $P_0=e_1$，投影后为零，损失停在 0.5；若重新选出 $P_1=e_2$，第二次更新为 $\operatorname{diag}(0,1)$，得到 $W_2=\operatorname{diag}(2,1)$，损失为零、累计变化秩为 2。这个例子解释了 Fig. 2 的必要性：单次压缩量小，不要求整个训练过程只学同一个方向。

由此还可以提出一个**原创待测规则**：当 $G\ne0$ 时，监测相对残差 $e=\sqrt{1-\|P^\top G\|_F^2/\|G\|_F^2}$。上例两步在旧基下分别为 $0.4472$ 和 $1$；假设阈值为 0.8，第二步触发重选，第一步不触发。公式利用正交投影的能量分解，避免显式重建整份残差。这是从算例得到的研究建议，0.8 没有经过任务验证，也不是 GaLore 的既有参数；比较这种触发方式时，还应配平或报告 SVD 次数，防止把额外计算当成规则本身的收益。

再核算一份实际可实现的状态预算。若某层 $m=64,n=128,r=8$，完整 Adam 两组统计需 $2mn=16384$ 个数；GaLore 的投影基和两组统计需 $mr+2nr=512+2048=2560$ 个数。全部按 FP32 保存时分别是 65536 与 10240 字节。连同双方相同的 8192 个权重，合计为 98304 与 43008 字节。这里未计入梯度、激活、SVD 工作区和临时更新，不能当作设备峰值内存；它只用来判断优化器状态是否值得压缩。

### 原创英文差段与完整改段

**差段：** “The calibration model has low-rank gradients, so it can always be trained in a fixed subspace without losing accuracy. We refresh the subspace every 200 steps because this setting works well. Figure 5 shows that a smaller rank is more efficient, and therefore our method can recover from wireless changes faster.”

**诊断。** 差段把局部梯度结构写成所有阶段的固定性质，把刷新周期写成无解释的常数，又从较少状态跳到了更快恢复。三个结论之间缺少实验支持。

**完整改段：** “A compact gradient representation reduces optimizer-state storage, but a fixed projection can discard useful updates when the dominant gradient directions change. We therefore refresh the projection periodically while retaining all previous updates in the model weights. To identify a useful refresh interval, we vary the interval at several ranks and measure both task loss and refresh cost. We then compare rank settings using two views: loss after a fixed number of updates and elapsed time to a common target loss. The first view reveals the effect of restricting the update space; the second determines whether the saved state permits a practical recovery schedule on the gateway. The refresh interval is selected from these measurements rather than transferred unchanged from the language-model experiment.”

改段为原创无线实验设计，未声称已做恢复实验。它保留论文的“空间变了，所以重选；重选有代价，所以扫周期”逻辑，同时补上恢复时限真正需要的时间指标。可迁移搭配是 **retain all previous updates in the model weights**，适合解释状态压缩后历史学习结果保存在哪里；若方法会回滚或重置权重，就不能使用这句。

## 本批表达练习

**preserve the candidate interventions** 指保留后续选择需要比较的动作，需要定义集合。原创例句：We learn only the relationships needed to preserve the candidate interventions.

**marginal gains diminish** 表达继续增加资源时增量收益变小。原创例句：The marginal gains diminish after the background window covers enough recent observations.

**retain all previous updates in the model weights** 说明更换压缩状态后累积学习结果保存在哪里。原创例句：We refresh the projection while retaining all previous updates in the model weights.
